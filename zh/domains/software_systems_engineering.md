# Software & Systems Engineering

> [English](../../domains/software_systems_engineering.md) | **简体中文**

## Scope

作为工程的软件构建与验证：真实仓库上的代码生成、环境配置、形式化规约与验证。Web/UI agent 与 computer use 不属于软件工程。

## Related Works

- [SWE-bench](../works/swe-bench.md) — 在开源 Python 仓库的真实 GitHub issue 上生成补丁。
- [SWE-chat](../works/swe-chat.md) — 真实环境 coding-agent 会话，带以 commit 为锚点的作者归属。
- [Enconda-bench](../works/enconda-bench.md) — 面向软件工程 agent 的环境配置。
- [AgentLens](../works/agentlens.md) — 在真实开源 Spring Boot 项目上的 Java 编码助手任务。
- [SysMoBench](../works/sysmobench.md) — 并发与分布式系统的 TLA+ 形式化建模。
- [VCoT-Bench](../works/vcot-bench.md) — 在 Verus 中对 Rust 程序做形式化验证。
- [Long-Horizon-Terminal-Bench](../works/long-horizon-terminal-bench.md) — 其长 horizon 终端工作流中的软件工程与科学计算。
