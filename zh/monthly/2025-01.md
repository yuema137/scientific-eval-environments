## 这个月到底变了什么

### [Scientific Agent Benchmarks](../../topics/scientific_agents.md)

这组工作主要在回答一个更硬的问题：进到真实 scientific workflow 以后，benchmark 到底该怎么做，才不至于只是在测一层表面问答。

- [Gravity-Bench-v1](../../works/gravity-bench.md)：Gravity-Bench-v1 是引力物理发现的 agentic benchmark：agent 观测一个模拟二体引力系统，在实验预算内规划采集哪些数据，再通过数据分析揭示被隐藏的物理：包括无法靠背诵教科书知识回答的、分布外的修改物理。
- [Humanity's Last Exam](../../works/hle.md)：Humanity's Last Exam（HLE）是位于人类知识前沿的多模态 benchmark，定位为同类封闭式学术评测的「最后一份考卷」：2,500 道题目横跨数十个学科：数学、人文与自然科学：由全球领域专家共同出题。它是通用学术 benchmark 而非 agent benchmark（见 Limitations 中的 repository note）。
- [Using Large Language Models for Solving Thermodynamic Problems](../../works/llm-thermodynamics.md)：一项 benchmark 研究：在 22 道化工热力学题目上评估五个大语言模型，答案由受过训练的人类专家按学术考试的判卷方式打分。
- [Materials Hypothesis Generation](../../works/materials-hypothesis.md)：本工作评测目标驱动、约束引导的 LLM agent 用于材料发现：给定研究目标与具体约束，agent 生成实现目标的假说，由一个可扩展的评估指标判分：该指标旨在模拟材料科学家会如何批判性地评判一个假说。
- [MedAgentBench](../../works/medagentbench.md)：MedAgentBench 是评测医疗 LLM agent 的真实感虚拟 EHR 环境：300 个由人类医生撰写、面向具体患者的临床任务（10 个类别），运行在 100 位患者、逾 70 万数据元素的真实感档案之上，环境符合 FHIR 标准且可交互。

### [General Long-Horizon Agent Benchmarks](../../topics/long_horizon_evaluation.md)

这组工作盯住的是同一个难点：一旦 agent 得跨很多步维持状态，benchmark 就得把卡住的位置露出来。

- [EmbodiedEval](../../works/embodiedeval.md)：EmbodiedEval 在一个交互式 3D 模拟框架中把多模态 LLM 当作具身 agent 来评测：125 个多样 3D 场景中的 328 个任务，横跨导航、物体交互、社交互动、属性问答与空间问答五个类别。

### [Resource-aware Evaluation](../../topics/resource_aware_evaluation.md)

这组工作把资源也算进分里，所以不是成了就行，还得看 agent 是不是花得有章法。

- [Gravity-Bench-v1](../../works/gravity-bench.md)：Gravity-Bench-v1 是引力物理发现的 agentic benchmark：agent 观测一个模拟二体引力系统，在实验预算内规划采集哪些数据，再通过数据分析揭示被隐藏的物理：包括无法靠背诵教科书知识回答的、分布外的修改物理。
