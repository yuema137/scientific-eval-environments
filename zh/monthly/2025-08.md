## 这个月到底变了什么

### [Scientific Agent Benchmarks](../../topics/scientific_agents.md)

这组工作主要在回答一个更硬的问题：进到真实 scientific workflow 以后，benchmark 到底该怎么做，才不至于只是在测一层表面问答。

- [CEQuest](../../works/cequest.md)：CEQuest 是一个含 164 道题目的 benchmark，考察施工图纸解读与工程造价估算。题目由领域专家依据造价估算教材与图纸解读指南编写，并用于在准确率、评测耗时与模型规模三个维度上比较五个 LLM。
- [CMPhysBench](../../works/cmphysbench.md)：CMPhysBench 是凝聚态物理领域的 benchmark，含 520 余道精心整理的研究生水平计算题，用 Scalable Expression Edit Distance（SEED）：一种对解答表达式的细粒度、非二元部分得分：进行评分。
- [FGBench](../../works/fgbench.md)：FGBench 在官能团粒度上评估分子性质推理：62.5 万个生成的推理问题，标注了是 245 个官能团中的哪一个驱动了性质差异；另设 7,000 个精选子集用于评测最先进的 LLM。
- [QCBench](../../works/qcbench.md)：QCBench 评估 LLM 的领域定量化学能力：350 个计算题覆盖 7 个化学子领域、分三档难度，题目结构上防住启发式捷径，必须做显式的分步数值推理。

### [Benchmark Design, Validity & Contamination](../../topics/benchmark_design_validity_contamination.md)

这组工作真正追问的是：一旦把泄漏、构造偏差和 grader 设计都摆上台面，这个分数还信不信得过。

- [CODE2BENCH](../../works/code2bench.md)：CODE2BENCH 是动态 benchmark 构造框架。它从近期真实 code repository 中取材，为 Python 和 Java 生成任务，并要求测试达到 100% branch coverage 才能入库。
