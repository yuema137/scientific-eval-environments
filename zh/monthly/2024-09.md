# 2024 年 9 月月度报告

> [English](../../monthly/2024-09.md) | **简体中文**

> **覆盖范围：** 2024-09 首次公开的工作

## 本月概览

- 本月共有 **4 项工作**进入知识库，全是**当月新发布**，都在 2024 年 9 月首次公开：[SUPER](../../works/super.md)、[DSBench](../../works/dsbench.md)、[CORE-Bench](../../works/core-bench.md) 和 [ChemEval](../../works/chemeval.md)。
- 这四项全归在 [Scientific Agent Benchmarks](../../topics/scientific_agents.md) 底下，共同的一招是：不给 agent 一道包装好的题，而是把真实科研里的原始材料直接扔给它，再去量它到底能做完多少；而答案是，做完的只有一小点。
- 挨得最紧的一簇是研究复现。[CORE-Bench](../../works/core-bench.md) 和 [SUPER](../../works/super.md) 都从已经公开的研究产物起步，但下刀的关节不一样；两家给出的天花板都压在大约五分之一甚至更低。
- [DSBench](../../works/dsbench.md) 和 [ChemEval](../../works/chemeval.md) 把这条前线推进到数据科学和化学。ChemEval 是本月唯一一个走静态能力画像、而不是 agent 解题成功率的工作，也是唯一一个还挂在 [Skill Hierarchy](../../topics/skill_hierarchy.md) 上的。

## 这个月到底变了什么

**科学 agent 的评测，从已经排好版的题目，挪到了真实工作留下的原始产物上，而且每一个新天花板都很低。** 先看老一套的评测怎么喂题：递给模型的是一道已经替它收拾干净的题，任务描述是精挑细选整理过的，问题自成一体，输入也排好了格式，模型一拿到就能直接推理。这么测，测的是「准备工作都做完之后」的推理能力，可对准备工作本身它一句话都没说：那个死活装不上的依赖、那个多张表拼在一起的数据文件、那篇数字得真能跑回来的论文。本月这四项工作，改的正是「给 agent 什么」这件事。每一项都把一线研究者真会碰上的、没打磨过的输入原样递过去，再看研究者要的那个结果到底出没出来；四项的结论一致：真正做完的只有一小块。

最清楚的一簇是研究复现。[CORE-Bench](../../works/core-bench.md) 和 [SUPER](../../works/super.md) 的起点是同一个：一项研究自己公开出来的代码和数据；但它俩下刀的关节不一样。[SUPER](../../works/super.md)（出自 AI2）单拎出来的是最上游那一步，也就是先把别人的仓库跑起来这件事：解决依赖、修报错、把 GitHub 上真实 ML/NLP 仓库里的代码执行出来。评分覆盖三部分：45 道带专家解法的端到端问题、152 道把单个搭环境难点隔离出来的子问题，以及 602 道自动生成的问题。表现最好的模型 GPT-4o，端到端那一档只做对 16.3%（按场景算是 46.1%）。[CORE-Bench](../../works/core-bench.md) 量的是复现的结果那一头：一篇已发表研究报告里的数字，能不能靠它自己给的代码和数据重新跑出来。它一共 270 个任务，取自计算机科学、社会科学和医学的 90 篇论文，分三个难度档，还分成纯语言和视觉语言两种形式；配套一套并行化的评测框架，比顺序跑一遍能省下好几天。它最强的基线，在最难那一档也就 21% 的准确率。两个放一起看：SUPER 量的是代码跑不跑得起来，CORE-Bench 量的是数字回不回得来；而这俩离「把研究自动化的这块地板跨过去」都还差得远。

[DSBench](../../works/dsbench.md) 把同一种「真实感」推进到数据科学。它不给那种干净的玩具表格，540 个任务（466 个数据分析、74 个数据建模）带着长篇文字背景、图片，还有从竞赛平台和 Kaggle 上取来的多表数据；agent 得把一句指令加上一堆数据文件，变成一个真能用的解法。把分析和建模拆开，是为了单独看两种不一样的本事，结果两边成绩都不好看：最好的 agent 只做对 34.12% 的分析任务，在建模上还有 34.74% 的相对性能差距；这个数可以直接拿来引用，标出 agent 离专家级数据科学工作到底还差多远。

[ChemEval](../../works/chemeval.md) 是本月在形式上的一个例外：它给的不是 agent 解题成功率，而是一份静态的能力画像。它把化学能力拆成四个层层递进的级别、12 个维度，一共 42 个任务；数据既有开源的，也有化学专家亲手出的题，再用零样本和少样本两种提示方式去测 12 个模型。它给出的不是一个天花板，而是一处此消彼长：GPT-4、Claude-3.5 这类通用模型，在文献理解和指令遵循上领先，可一到高阶化学知识就落了下风；专门的化学模型反过来。因为这几个级别是层层递进的，后面的能力得先有前面的打底，这份画像读起来就是一套能力的结构，所以这项工作也归到 [Skill Hierarchy](../../topics/skill_hierarchy.md) 下面。要说边界，它停在静态的单轮问答上，没走到交互式的场景；而且报出来的数字跟版本有关：arXiv 版本写的是 42 个任务、12 个维度，官方仓库对应的那个更晚的 ICLR 版本，则扩到了 62 个文字和多模态任务、13 个维度。

## 值得展开的 Topic

### [Scientific Agent Benchmarks](../../topics/scientific_agents.md)

四项工作全落在这个 Topic 下，但它们不是堆成一堆，而是分出几条能认得出来的设计路线。复现这条线（[CORE-Bench](../../works/core-bench.md)、[SUPER](../../works/super.md)）在 Topic 内部划出一道界：两家都从公开的研究产物起步，可一个考的是搭环境和执行，另一个考的是报告里的结果能不能复原；这是同一条链上前后紧挨着的两环，却被分开各测各的。数据科学这条线（[DSBench](../../works/dsbench.md)）保留了「agent 亲手产出一个解法」这个框架，但把复现换成了在杂乱的多模态输入上做开放式的分析和建模。领域知识这条线（[ChemEval](../../works/chemeval.md)）干脆不走 agent 这条轴了，改用静态的「级别加维度」画像，把一个单一成功率会藏起来的东西亮出来：通用模型和专用模型之间的那道分野。

同样这几项工作，还挨着另外两条相邻的轴，这里只做交叉链接，不重复展开：

- [General Long-Horizon Agent Benchmarks](../../topics/long_horizon_evaluation.md)：[SUPER](../../works/super.md) 能算进来，是因为它「搭仓库加执行」的这一段是要交互的、长程的；这个任务的长短，是由搭环境那条轨迹的长度定的，不是一次查询就完事。
- [Skill Hierarchy](../../topics/skill_hierarchy.md)：[ChemEval](../../works/chemeval.md) 那几个层层递进的级别，起的是一个把能力排出高低的作用：高阶化学本事得先有下面几层垫着，而不是再添一个平级的类别。
