# 2026-08 月度报告

> [English](../../monthly/2026-08.md) | **简体中文**

> **覆盖范围：** 2026-08 首次公开的工作

## 本月概览

2026 年 8 月是目前档案里最密的一个月，一共 39 项新工作。它看起来已经不像某一条单一趋势在变强，而更像整个领域开始拆成几块彼此区分很清楚的子问题。Scientific benchmarking 还是最大头，但真正值得注意的是另外三条线也同时站起来了：trajectory evaluation 开始像一门独立的诊断方法学；long-horizon benchmark 不再只看任务做没做完，而开始把 agent improvement loop 也纳进来；evaluator reliability 这件事本身，也终于开始被系统性地测。

这个月也最容易把仓库那句“evaluation drives development”讲明白。很多 8 月工作问的已经不只是 agent 成没成，而是 telemetry 够不够诊断、replay 靠不靠谱、judge 能不能信、harness 会不会自己改、以及 benchmark 到底能不能预测 benchmark 之外的表现。

## 这个月到底变了什么

### [Scientific Agent Benchmarks](../../topics/scientific_agents.md)

8 月的 scientific benchmark 已经不是一类东西了，至少能分成三种很清楚的路数。第一种，是继续把 benchmark 往真实 scientific 或 engineering workflow 里压。[Agentic Self-Driving Microscopy Benchmarks](../../works/agentic-microscopy-benchmarks.md)、[AutoResearchEval](../../works/autoresearcheval.md)、[PACE-Bench](../../works/pace-bench.md)、[DSAgentBench](../../works/dsagentbench.md)、[CRAFTS](../../works/crafts.md)、[MMArch](../../works/mmarch.md)、[TCS-Bench](../../works/tcs-bench.md)、[EnergyBridge](../../works/energybridge.md)、[BrainBench (EEG)](../../works/brainbench-eeg.md) 这些工作一起，把“专业 workflow 能不能被 operationalize 成 evaluator”这件事继续往前推。

第二种更偏诊断和社会技术结构。[Agents Catching Agents](../../works/agents-catching-agents.md) 问的是，多 agent 讨论时会不会被临床上根本不该采信的捷径线索带偏；[Apodex Discovery](../../works/apodex-discovery.md) 则是对 discovery 过程本身打盲分，按六个过程维度看轨迹；[Science Edge Evaluation (SEE)](../../works/science-edge-evaluation.md)、[Replica](../../works/replica.md)、[Fisher-R1 / P-Bench](../../works/fisher-r1.md)、[onepot-Bench 0](../../works/onepot-bench.md) 又分别从 realism、replicability、benchmark design 等不同地方加压。[Position: AI Agents in Scientific Teams Should Be Studied as Human-Agent Systems](../../works/ai-agents-in-scientific-teams.md) 和 [Co-Evolution in Agentic Systems: Toward Self-Directed Evolution Beyond Human Design](../../works/co-evolution-agentic-systems-survey.md) 虽然不算狭义 benchmark paper，但它们把这个月很多实证工作背后的组织问题点亮了：agent 从来不是在真空里被评的。

所以 8 月最值得记住的，不是又冒出一个新的“最标准 benchmark”，而是 benchmark landscape 明显开始分化，而且这种分化是健康的：有些 evaluator 更关心 workflow fidelity，有些关心 discovery process，有些关心 team dynamics，还有些干脆先追问这个 benchmark 到底能不能预测测试集之外的东西。

### [Trajectory Evaluation](../../topics/trajectory_evaluation.md)

8 月的 trajectory evaluation，已经开始像一条独立研究线了。[AutoResearchEval](../../works/autoresearcheval.md)、[Beyond Final Scores](../../works/beyond-final-scores.md)、[SWE-RPG](../../works/a-unified-issue-resolution-benchmark-for-requireme.md)、[SearchAuditor](../../works/searchauditor.md)、[TRAJDEBUG](../../works/trajdebug.md)、[TelemetrySuffBench](../../works/telemetrysuffbench.md)、[The Replay Gap](../../works/the-replay-gap.md) 这些工作，表面看题材不同，但其实都在追问同一类事：一条 agent run 到底要留下什么证据，才够你诊断、重放、归因、或者公平比较？

这个月最重要的变化，是文献终于开始把过去糊在一起的几个子问题分开。第一条线问：trace 本身信息够不够，够不够支撑诊断。第二条线问：replay 或 reconstruction 出来的轨迹，还保不保留原始决策信号。第三条线问：stage-level 或反事实分析，能不能把 planning 质量和后段 execution 翻车拆开。到这一步，trajectory evaluation 已经不只是“给中间步骤打分”，而是在慢慢变成把 agent behavior 变成可检查证据的方法学。

### [General Long-Horizon Agent Benchmarks](../../topics/long_horizon_evaluation.md)

8 月的 long-horizon 工作，气质也变了。[RoboGraphBench](../../works/compiling-and-benchmarking-task-state-horizons-for.md) 和 [PATH-Bench](../../works/path-bench.md) 还在处理比较经典的问题：一个 agent 跨很多步维持相关状态到底有多难。但 [Evo-Bench](../../works/evo-bench.md)、[HarnessOpt-Bench](../../works/harnessopt-bench.md)、[R³-Bench](../../works/r3-bench.md)、[SkillMisevo-Bench](../../works/skillmisevo-bench.md)、[SWE-Bench ProMax](../../works/swe-bench-promax.md)、[PACE-Bench](../../works/pace-bench.md) 把 scope 一下子拉宽了。长时程对象不再只是“把任务做完”，而越来越像“沿很多个决策去调 harness、配资源、迭代改系统”。

所以 8 月跟前面几个月不一样的地方在于：horizon 已经不只在任务里，也开始长到任务外面的 development loop 里去了。

## 值得展开的 Topic

8 月当然还是 [Scientific Agent Benchmarks](../../topics/scientific_agents.md)、[Trajectory Evaluation](../../topics/trajectory_evaluation.md)、[General Long-Horizon Agent Benchmarks](../../topics/long_horizon_evaluation.md) 最居中，但这个月还有个很明显的新变化：像 [Evaluator Reliability & Validation](../../topics/evaluator_reliability_validation.md)、[Credit Assignment](../../topics/credit_assignment.md)、[Agent Harnesses & Scaffolding](../../topics/agent_harnesses_scaffolding.md)、[Skill Learning & Evolution](../../topics/skill_learning_evolution.md) 这些旁边页，已经不只是交叉引用了，它们开始在月报主叙事里自己出力。
