# 2024-08 月度报告

> [English](../../monthly/2024-08.md) | **简体中文**

> **覆盖范围：** 2024-08 首次公开的工作

## 本月概览

2024 年 8 月把 planning 和 execution 又往真实操作场景里推近了一步。TransportBench、SimBench、BLADE 和 PEOA 共同关心的，都是 practical constraints 下的结构化行动，不管 agent 面对的是运输规划、仿真运行，还是具身任务里的推理。

## 这个月到底变了什么

### [Scientific Agent Benchmarks](../../topics/scientific_agents.md)

这组工作主要在回答一个更硬的问题：进到真实 scientific workflow 以后，benchmark 到底该怎么做，才不至于只是在测一层表面问答。

- [BLADE](../../works/blade.md)：BLADE 为数据驱动科学评测语言模型 agent：12 个数据集配来自科学文献的研究问题，真值取自专家数据科学家的独立分析，考察 agent 能否在开放式分析中整合领域知识、统计学与数据理解。
- [PEOA](../../works/peoa.md)：PEOA（Process Engineering Operations Assistant）是一套面向化工与过程工程问题求解的模块化 LLM agent 框架，随框架一同发布的还有两个自建 benchmark 数据集：MathComp 与 ChemProc：以及一套分阶段的工具学习评测协议，用于将该框架与闭源 LLM 对比。
- [SimBench](../../works/simbench.md)：SimBench 评估并诊断 LLM 的数字孪生生成能力：面向仿真的 LLM 通过多轮交互为开源 Chrono 仿真器构建数字孪生：多体动力学、有限元分析、车辆动力学、机器人动力学与传感器仿真：由带预定义规则与人在环指导的 LLM judge 打分。
- [TransportBench](../../works/transportbench.md)：TransportBench 是一个含 140 道本科交通工程题目的数据集，题目取自 University of Illinois 的两门土木工程课程，配以人类专家评分，用于测量七个商业与开放权重 LLM 的准确率、答案一致性与推理行为。

### [Trajectory Evaluation](../../topics/trajectory_evaluation.md)

这一组不再只盯最后答案。整条 trajectory 本身就是证据，能看出 agent 当时看见了啥、怎么决定的、又漏掉了啥。

- [PEOA](../../works/peoa.md)：PEOA（Process Engineering Operations Assistant）是一套面向化工与过程工程问题求解的模块化 LLM agent 框架，随框架一同发布的还有两个自建 benchmark 数据集：MathComp 与 ChemProc：以及一套分阶段的工具学习评测协议，用于将该框架与闭源 LLM 对比。

### [Skill Hierarchy](../../topics/skill_hierarchy.md)

这组工作不把能力压成一个总分，而是把结果背后的几层 subskill 拆开来看。

- [PEOA](../../works/peoa.md)：PEOA（Process Engineering Operations Assistant）是一套面向化工与过程工程问题求解的模块化 LLM agent 框架，随框架一同发布的还有两个自建 benchmark 数据集：MathComp 与 ChemProc：以及一套分阶段的工具学习评测协议，用于将该框架与闭源 LLM 对比。

## 值得展开的 Topic

[Scientific Agent Benchmarks](../../topics/scientific_agents.md)、[Trajectory Evaluation](../../topics/trajectory_evaluation.md)、[Skill Hierarchy](../../topics/skill_hierarchy.md) 还是这个月最该连起来看的几页，但重点不在于把名字列出来。把这几页一起看，能看到一个很明确的变化：scientific benchmark 一旦开始把结果背后的中间证据露出来，它才真正变得对诊断和改进有用。
