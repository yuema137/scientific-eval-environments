## 本月概览

2024 年 11 月量不大，但方法上混得很有用。RE-Bench、OpenCATP、RoboSpatial、MaCBench 和 EEE-Bench 把 evaluation 往预算、具身几何和协同操作这些地方都伸进去了，于是 resource limits 和 physical context 这两件事越来越没法再当成事后备注。

## 这个月到底变了什么

### [Scientific Agent Benchmarks](../../topics/scientific_agents.md)

这组工作主要在回答一个更硬的问题：进到真实 scientific workflow 以后，benchmark 到底该怎么做，才不至于只是在测一层表面问答。

- [EEE-Bench](../../works/eee-bench.md)：EEE-Bench 是一个综合的多模态电气与电子工程 benchmark：2,860 个精选问题，横跨 10 个核心子领域（模拟电路、控制系统等），要求在专业指令之外读懂抽象电路、系统框图等复杂图像：17 个 LLM 与 LMM 的平均成绩仅 19.48%–46.78%。
- [MaCBench](../../works/macbench.md)：MaCBench 探测多模态（视觉-语言）模型在化学与材料研究中的局限，覆盖三个核心方面：数据抽取、实验理解、结果解读：模型在仪器识别与标准化数据抽取上近乎完美，但在空间推理、跨模态信息综合与多步逻辑推断上存在根本性局限。
- [RE-Bench](../../works/re-bench.md)：RE-Bench（Research Engineering Benchmark，v1）在前沿 AI R&D 能力上对照人类专家评测语言模型 agent：7 个带参考解的开放式 ML 研究工程环境，加上 61 位人类专家 71 次 8 小时尝试的数据：2 小时预算下 agent 得分是人类的 4 倍，但到 32 小时人类反超到 2 倍。

### [Resource-aware Evaluation](../../topics/resource_aware_evaluation.md)

这组工作把资源也算进分里，所以不是成了就行，还得看 agent 是不是花得有章法。

- [CATP-LLM / OpenCATP](../../works/catp-llm.md)：CATP-LLM（Cost-Aware Tool Planning with LLMs）是一个让 LLM 在考虑工具执行成本的前提下进行工具规划的框架，并伴随 OpenCATP：被称为首个面向 cost-aware planning 的数据集（11,100 个评估样本）。本仓库为其 cost-aware *评估*贡献（OpenCATP）而收录它；论文的头号贡献：CATP-LLM 规划方法：是与本仓库评估焦点相邻的 agent 规划工作（见 Limitations 中的 repository note）。

### [Skill Hierarchy](../../topics/skill_hierarchy.md)

这组工作不把能力压成一个总分，而是把结果背后的几层 subskill 拆开来看。

- [MaCBench](../../works/macbench.md)：MaCBench 探测多模态（视觉-语言）模型在化学与材料研究中的局限，覆盖三个核心方面：数据抽取、实验理解、结果解读：模型在仪器识别与标准化数据抽取上近乎完美，但在空间推理、跨模态信息综合与多步逻辑推断上存在根本性局限。
