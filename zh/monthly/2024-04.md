# 2024-04 月度报告

> **覆盖范围：** 2024-04 首次公开的工作

## 本月概览

2024 年 4 月只有两项工作，但对比特别有力，因为它把一件事讲透了：headline score 到底说明什么，很大程度上取决于交互表面。ChemBench 评的是静态 chemistry knowledge，OSWorld 评的是长动作链上的真实 computer use，所以“模型能力”和“agent 能力”从这个月开始就不该再混着说。

## 这个月到底变了什么

### [Scientific Agent Benchmarks](../../topics/scientific_agents.md)

这组工作主要在回答一个更硬的问题：进到真实 scientific workflow 以后，benchmark 到底该怎么做，才不至于只是在测一层表面问答。

- [ChemBench](../../works/chembench.md)：ChemBench 追问的是大语言模型是否已是「超人化学家」：一套自动化评估框架，用 2,700 多个精心策划的问答对，把领先的开源与闭源 LLM 与人类化学家的专业水平直接对比：研究中最强的模型平均成绩超过了最强的人类化学家。

### [General Long-Horizon Agent Benchmarks](../../topics/long_horizon_evaluation.md)

这组工作盯住的是同一个难点：一旦 agent 得跨很多步维持状态，benchmark 就得把卡住的位置露出来。

- [OSWorld](../../works/osworld.md)：OSWorld 是一个面向多模态 agent 的可扩展真实计算机环境，支持跨 Ubuntu、Windows 与 macOS 的任务设置、基于执行的评估与交互式学习。它提供 369 个真实计算机任务，涵盖 web 与桌面应用、操作系统文件 I/O 与多应用工作流。

## 值得展开的 Topic

[Scientific Agent Benchmarks](../../topics/scientific_agents.md)、[General Long-Horizon Agent Benchmarks](../../topics/long_horizon_evaluation.md) 还是这个月最该连起来看的几页，但重点不在于把名字列出来。最值得看的连接点在于：scientific evaluation 正在被推向真实的多步环境，而不再停在静态领域 QA 那一层。
