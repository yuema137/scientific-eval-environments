## 本月概览

本月共有 22 项工作首次公开。先看文献最集中的方向：Scientific Agent Benchmarks、Trajectory Evaluation、General Long-Horizon Agent Benchmarks。

## 这个月到底变了什么

### [Scientific Agent Benchmarks](../../topics/scientific_agents.md)

把这组工作放一块看，变化不只是多了几个分数，而是 evaluator 能看见、能诊断的东西变多了：

- [AstroVisBench](../../works/astrovisbench.md)：AstroVisBench 是面向天文学科学计算与可视化的代码 benchmark：模型要先实现一套天文专属的数据处理工作流，再画出能传达预期科学洞见的图。可视化由一条 VLM-as-a-judge 流水线打分，这条流水线以五位职业天文学家的标注为对照做过校验。
- [BAISBench](../../works/baisbench.md)：BAISBench 以两项任务评测「AI scientist」在组学数据驱动的生物学发现上的能力：在 15 个专家标注的单细胞数据集上做细胞类型注释，并回答 193 道由 41 项已发表单细胞研究的生物学结论派生的选择题：另配六位研究生水平生物信息学家的人类基线。
- [BiomedSQL](../../works/biomedsql.md)：BiomedSQL 是一套 text-to-SQL benchmark，建在一个统一整合的生物医学知识库上，库中含基因–疾病关联、组学因果推断结果与药物审批记录；要答对一道题，模型必须自行补上问题从未言明的领域判据：全基因组显著性阈值、效应方向、试验期相筛选条件。
- [BioProBench](../../works/bioprobench.md)：BioProBench 是生物实验协议推理的语料与 benchmark：22,413 份人工撰写的协议（BioProCorpus）扩展为 523,784 个任务实例，覆盖五类任务：协议问答、步骤排序、错误纠正、协议生成与协议推理。
- [ChemCoTBench](../../works/chemcotbench.md)：ChemCoTBench 把化学评估从问答推进到「模块化化学操作」：添加、删除、取代等操作把分子变换拆成透明的分步工作流：1,495 个样本覆盖 22 个任务，集中在分子性质优化与化学反应预测两大类。

说白了，这批工作共同往前推了一步：不能只看最后成没成，还得把行为、证据或改进环节摊开，才能知道下一步该改哪儿。

### [Trajectory Evaluation](../../topics/trajectory_evaluation.md)

把这组工作放一块看，变化不只是多了几个分数，而是 evaluator 能看见、能诊断的东西变多了：

- [AstroVisBench](../../works/astrovisbench.md)：AstroVisBench 是面向天文学科学计算与可视化的代码 benchmark：模型要先实现一套天文专属的数据处理工作流，再画出能传达预期科学洞见的图。可视化由一条 VLM-as-a-judge 流水线打分，这条流水线以五位职业天文学家的标注为对照做过校验。
- [RoboFAC](../../works/robofac.md)：RoboFAC 是机器人失败分析与纠正的综合框架：9,440 条错误操作轨迹、78,623 个 QA 对、53 个场景，覆盖模拟与真实世界环境，失败类型经系统归类；配有覆盖八个 QA 维度的 benchmark，以及专用模型 RoboFAC-7B：其失败分析准确率比 GPT-4o 高 34.1%。
- [Traxgen](../../works/traxgen.md)：Traxgen 是一个面向 AI-agent 评估的**确定性** ground-truth trajectory 生成工具包。它把结构化的 workflow 规范与用户数据编译成一份有向无环图（DAG），进而生成完整规定的参考 trajectory：把 LLM 从 ground-truth 生成流程中移除。论文同时发布一份含 675 个任务实例的配套 benchmark，用于以 Traxgen 生成的参考对比六个 LLM 的规划能力。

说白了，这批工作共同往前推了一步：不能只看最后成没成，还得把行为、证据或改进环节摊开，才能知道下一步该改哪儿。

### [General Long-Horizon Agent Benchmarks](../../topics/long_horizon_evaluation.md)

把这组工作放一块看，变化不只是多了几个分数，而是 evaluator 能看见、能诊断的东西变多了：

- [MLE-Dojo](../../works/mle-dojo.md)：MLE-Dojo 是训练、评估并改进自主 LLM agent 做机器学习工程的 Gym 式交互环境：200+ 个真实 Kaggle 挑战，配结构化反馈循环，覆盖数据处理、架构搜索、超参调优与代码调试，在八个前沿 LLM 上评估。
- [MLR-Bench](../../works/mlr-bench.md)：MLR-Bench 在开放式机器学习研究上评测 AI agent：201 个取自 NeurIPS、ICLR、ICML workshop 的研究任务，覆盖想法生成、方案拟定、实验与论文写作，由 MLR-Judge：一个结合 LLM 评审与评分标准的自动框架：评分。
