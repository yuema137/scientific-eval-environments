## 这个月到底变了什么

### [Scientific Agent Benchmarks](../../topics/scientific_agents.md)

这组工作主要在回答一个更硬的问题：进到真实 scientific workflow 以后，benchmark 到底该怎么做，才不至于只是在测一层表面问答。

- [AIRS-Bench](../../works/airs-bench.md)：AIRS-Bench (AI Research Science Benchmark) 是面向 LLM agent 的 frontier 研究科学任务套件，共 20 个任务，覆盖全研究生命周期，跨越语言建模、数学、生物信息学与时间序列预测：且不提供 baseline 代码。
- [AutoBM / BMEval](../../works/autobm.md)：AutoBM 定义了这样一项任务：依据自然语言的结构描述，生成可执行且物理自洽的 OpenSeesPy 建筑模型代码。配套的 BMEval 则是一个以验证为驱动的 benchmark，含 128 个经专家验证的建模任务，按沙箱执行、自振周期吻合度与设计规范符合性三方面判分。
- [ChemCensor / CREED](../../works/chemcensor.md)：ChemCensor 是单步逆合成的评估方法学：用化学合理性指标取代「对照单一真值的 Top-K 精确匹配」；同一套验证器还生成了 CREED：数百万条经验证的反应记录，用于 LLM 训练。
- [ERI Benchmark](../../works/eri-benchmark.md)：Engineering Reasoning and Instruction（ERI）benchmark 是一套由分类体系驱动的指令数据集：按九个工程领域（含 55 个子领域，化学工程在列）、七种任务意图与三个难度层级做受控笛卡尔积，共 57,750 条指令–回答记录，随附校验脚本与一套用于给 LLM 和 agent 打分的评估框架。
- [FIRE-Bench](../../works/fire-bench.md)：FIRE-Bench（Full-cycle Insight Rediscovery Evaluation）是一个 benchmark，要求 agent 在仅获得已发表研究的高层研究问题的情况下，重新发现近期高影响力机器学习研究中确立的、可验证的结论。它包含 40 个完整执行的任务，以及另行发布供社区评估的 60 篇论文。

### [General Long-Horizon Agent Benchmarks](../../topics/long_horizon_evaluation.md)

这组工作盯住的是同一个难点：一旦 agent 得跨很多步维持状态，benchmark 就得把卡住的位置露出来。

- [Gaia2](../../works/gaia2.md)：Gaia2 是一个面向异步环境中 LLM agent 的 benchmark：在这类环境里，世界按自己的时钟推进，而非仅在 agent 行动时才变化。它的 1,120 个场景运行在一个模拟的智能手机世界中，由一个验证器对照 oracle 标注检查每一个改变状态的动作来打分，使该 benchmark 可直接用于基于可验证奖励的强化学习（RLVR）。
- [HiPER: Hierarchical Reinforcement Learning with Explicit Credit Assignment for Large Language Model Agents](../../works/hiper.md)：
- [TRACE](../../works/trace.md)：TRACE (Trajectory-Aware Comprehensive Evaluation) 是面向 deep research agent 的评估框架：通过 hierarchical utility function 对整条推理 trajectory 打分，并通过测量"成功所需最少引导"来量化 agent 的潜在能力。论文同时发布 DeepResearch-Bench，一个可控复杂度的配套 benchmark。

### [Credit Assignment](../../topics/credit_assignment.md)

这一组关心的是，功劳和责任到底该落在哪一步，而不是让一个最终分数把整段过程全糊成一片。
