## 这个月到底变了什么

### [Scientific Agent Benchmarks](../../topics/scientific_agents.md)

这组工作主要在回答一个更硬的问题：进到真实 scientific workflow 以后，benchmark 到底该怎么做，才不至于只是在测一层表面问答。

- [CosmoPaperQA](../../works/cosmopaperqa.md)：CosmoPaperQA 是一份含 105 组问答对的宇宙学问答数据集，题目取自五篇高引宇宙学论文。它用来评测九种检索增强生成（RAG）agent 配置，以专家人工评分为对照，并据此校准一个 LLM-as-a-Judge 评分器，让它充当人工评估的替代。
- [DrafterBench](../../works/drafterbench.md)：DrafterBench 是一个开源 benchmark，考察 LLM agent 做土木工程施工图修改：以十二类修改任务和 46 个自制图纸操作工具构建出 1,920 道题，判分读的是记录下来的操作链，而不是渲染出来的图纸。
- [EngDesign](../../works/engdesign.md)：EngDesign 收录 101 项来自真实工程的**设计**任务，横跨九个工程方向。LLM 必须交出一份可用的设计成果，再由领域仿真器验证其功能是否达标，而不是拿去和参考答案比对。
- [From Queries to Criteria: Understanding How Astronomers Evaluate LLMs](../../works/from-queries-to-criteria-understanding-how-astrono.md)：一项实证研究，考察领域专家在真实工作现场究竟如何评判一个 LLM 系统：作者把一个天文文献 RAG 机器人四周部署期内的 368 条真实提问与 11 次访谈作归纳编码，提炼出一套提问类型学与五条评价准则，再据此构建并公开了一个 40 道题、由专家撰写答案的天文 benchmark，其自动打分协议已对照用户评分完成校验。
- [MMCircuitEval](../../works/mmcircuiteval.md)：MMCircuitEval 是评测 LLM 的首个以电路为中心的多模态 benchmark：3,614 个精选问答对，横跨数字与模拟电路、覆盖关键 EDA 阶段：从通用知识与规格到前端与后端设计：取自教科书、题库、数据手册与真实文档。

### [Survey](../../topics/survey.md)

把这组工作放一块看，关键是看它把 evaluation 里原来藏着的哪一层给掀出来了。

- [Evaluation and Benchmarking of LLM Agents: A Survey](../../works/agent-evaluation-benchmarking-survey.md)：*Evaluation and Benchmarking of LLM Agents: A Survey* 是一篇关于 LLM-agent 评估领域的综述：提出一个二维分类法，沿 evaluation objectives（评估什么）与 evaluation process（如何评估）组织现有工作，并强调面向企业部署的评估挑战。此处以**参考论文**（非 benchmark 贡献）纳入。

### [Trajectory Evaluation](../../topics/trajectory_evaluation.md)

这一组不再只盯最后答案。整条 trajectory 本身就是证据，能看出 agent 当时看见了啥、怎么决定的、又漏掉了啥。

- [DrafterBench](../../works/drafterbench.md)：DrafterBench 是一个开源 benchmark，考察 LLM agent 做土木工程施工图修改：以十二类修改任务和 46 个自制图纸操作工具构建出 1,920 道题，判分读的是记录下来的操作链，而不是渲染出来的图纸。
