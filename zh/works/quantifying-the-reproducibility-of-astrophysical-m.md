# Quantifying the Reproducibility of Astrophysical Methods with Large Language Models and Information Theory (2026)

> [English](../../works/quantifying-the-reproducibility-of-astrophysical-m.md) | **简体中文**

## Overview

一套信息论的评估方法：把 LLM 对某篇已发表天体物理方法的重建视为从算法空间上的一个分布中采样，用 Shannon 熵与 Jensen–Shannon 散度衡量论文文本把合法实现的空间约束得有多紧，并按四级的 Hierarchy of Scientific Validity 为前沿模型产出的可执行流水线打分。

## Summary

论文追问的是：一套计算天体物理方法，究竟有多少能从它的文字描述里还原出来。作者把重建表述为算法空间上的推断——给定文本 `X`，LLM 从 `P(Y | X)` 中采样候选重建 `Ŷ`，这个分布的熵就衡量了文本没能钉死的那部分。文本按三个嵌套层级提供：仅标题（T）、标题 + 摘要（TA）、标题 + 摘要 + 方法（TAM），层级之间的信息增益因此可以归因到论文的具体组成部分。同一层级体系上跑两组互补的实验：一组是用本地开源权重模型做的分布分析，另一组是功能性的压力测试——前沿模型必须写出可执行的 Python，再对照原作者的实现为其科学有效性打分。

## Tasks

一个天体物理案例研究：从稀疏的宽带测光出发，对海王星外天体（TNO）做概率化的光谱重建。该案例取自一项配套研究，其真值流水线由 PCA、核密度估计与有监督的梯度提升回归器组合而成，任务则在三种信息状态（T、TA、TAM）下各实例化一次。实验一用两个开源权重模型（DeepSeek-R1-Distill-Qwen-14B 与 GPT-oss-20b），在温度 0.75 下为每个信息状态、每个模型生成 N = 200 份重建，用于分布分析。实验二采用两阶段提示——先抽取算法，再实现 Python——在每个信息状态上跑三个前沿模型（Gemini 3.1 Pro、ChatGPT-5.2 与 Claude 4.6 Sonnet），随后执行一套数据替换协议，把模型自己合成的光谱换成原研究的真实观测数据。实验期间，作为对象的那项研究尚未发表，既无公开代码也无预印本，且所有结果都在其公开之前冻结，以限制记忆效应。

## Domains

天文——被重建的方法、真值与受评输出全是天文的：从稀疏测光重建海王星外天体的光谱（文中展示了海王星特洛伊天体 2010 TS191 与 2011 WG157），并以重建谱是否满足反射率非负这类物理约束来判定。作者称这套信息论框架具有普遍适用性，但真正实例化的领域只有天体物理。

## Evaluation

- **实验一（分布层面）。** 候选重建被投影到两个空间：词汇空间（在方法学关键词白名单上做 TF–IDF，再经 PCA 与 K-Means，K = 15）与语义空间（768 维 `jina-embeddings-v2-base-code` 嵌入，再经 UMAP 与 HDBSCAN）。各簇的频率构成算法上的离散分布，据此计算 Shannon 熵 `H`、信息状态之间的互信息增益、状态两两之间的 Jensen–Shannon 散度，以及与真值的对齐程度（词汇空间用 JSD，语义空间用余弦距离）。不确定度来自 1,000 次迭代的非参数 bootstrap 重采样。
- **实验二（功能层面）。** 生成的流水线在原始观测数据上实际运行，再由 human-in-the-loop 评审对照 **Hierarchy of Scientific Validity** 打分。这是一个序数指标 `V ∈ {0,1,2,3}`：0 为无效/不可执行或不合物理，1 为可执行但物理约束不足，2 为核心框架已还原但缺少隐含先验，3 为显式与隐含约束均已还原。作者规定 `V ≥ 2` 即为「功能上可由 LLM 重建」。评审沿三条准则展开：算法保真度、组件集成度与操作有效性。作者有意回避 RMSE 这类全局数值误差指标，理由是面对本质上概率性的目标，误差低反而可能掩盖表面化的模式匹配。
- **报告。** 从仅标题到完整方法，词汇熵在 DeepSeek 上由 3.65 降至 2.62 比特，在 GPT-oss 上由 3.54 降至 3.06 比特——也就是说，完整论文分别只传递了 1.03 与 0.48 比特的有效算法信息，留下一个非零的「熵地板」，而非坍缩到唯一实现。与真值的对齐则单调改善（词汇 JSD：DeepSeek 由 0.68 到 0.16，GPT-oss 由 0.71 到 0.26）。实验二中，三个前沿模型在仅标题下都得 `V = 0`，标题 + 摘要下得 `V = 1`，完整方法下得 `V = 2`，而作者自己的实现是经校准的 `V = 3` 参照；最终与真值的语义距离为 0.13（Gemini）、0.32（GPT-5）与 0.34（Claude）。信息增益与几何位移最大的一步出现在标题 → 摘要，而不是补上方法一节。

## Main Contribution

一种定量的零样本诊断手段，用于审计方法学透明度：通过测量论文写出来的内容与 LLM 集合所能重建出来的内容之间的残余散度，作者可以定位缺失的结构性约束。作者报告，作为研究对象的那项工作，其作者正是因为这次实验，在正式发表前修订了稿件，补上了此前遗漏的 Gaussian copula 描述。

## Key Design Ideas

- 把重建当作算法上的概率分布，而不是一次通过/失败的尝试，不确定性因此可测。
- 嵌套的输入层级（T ⊂ TA ⊂ TAM）把信息增益归因到论文的具体组成部分。
- 两个表示空间各司其职：词汇空间看选了*哪些*方法组件，语义空间看*怎样*实现。
- 聚类在跨全部信息状态的并集集合上进行，各分布因此共享同一离散支撑，散度才有良好定义。
- 真值取原作者实际使用的实现，并与该研究的首席研究员合作人工校准，而不是取文字描述或一类相似方法。
- 分布实验特意采用本地开源权重模型，以避开 API 的波动，使采样可复现。
- 打分依据的是一份公开的序数评分标准与明确的通过阈值，而非某个聚合的数值误差。

## Strengths

- 给出一套可复用、规格完整的测量协议——采样方案、聚类流水线、指标、评分标准与阈值一应俱全。
- 两组实验合计五个模型，构成真实的外部基线，而不是单一系统的演示。
- 真值经原作者确认，加上受测期间该研究尚未发表，这两点直接回应了记忆污染的疑虑。
- `V = 2` 与 `V = 3` 之分点出一个具体且可推广的失效模式：模型能拼出显式的流水线，却漏掉那些让结果在科学上真正校准的隐含统计约束（潜在协方差、选用非参数 KDE）。
- 论文坦承，观察到的熵地板可能有一部分是嵌入分辨率造成的假象，而非假设空间本身的性质。

## Limitations

- 只有一个案例研究：一篇论文的一套方法。框架的普适性是论证出来的，而不是在一批任务上演示出来的。
- 实验二的科学有效性得分来自定性的 human-in-the-loop 评审，未报告评审者间一致性。
- 两组实验用的模型集合互不相交（分布分析用开源权重模型，功能打分用前沿 API 模型），熵的测量结果与有效性得分因此无法归到同一批系统上。
- Repository note: 这是一套带公开评分标准的评估方法，而非已发布的 benchmark 套件——没有可供后来的系统打分的任务池，也无法从 arXiv 记录中核实代码或数据集地址（`TODO(reference)`）。
- Repository note: 受评系统是被提示的模型，而非会用工具的 agent；不存在环境交互与检索，模型自身也不做迭代调试。
