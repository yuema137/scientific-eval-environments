# Replica (2026)

> [English](../../works/replica.md) | **简体中文**

> **首次公开：** 2026-08-13 · **来源：** [arXiv 首次提交](https://arxiv.org/abs/2608.13331)

## Overview

Replica 是一个面向论文复现的任务空间：把一篇论文中的某张结果图不可逆地抹除，让 agent 依据论文其余部分把这张图重新做出来。随论文一同发布的还有一个自动生成、并与人类评分对标过的 rubric 评判器；作者用两者后训练出 Faraday——一个把编码 agent 当作工具来调用的 27B「AI 科学家」。

## Summary

作者认为复现一篇论文并不是查资料：复现这个动作本身会把原文含糊带过的细节逼出来，因此它既需要开放式研究那样由假设驱动的探索，又保留了一个可以核对的目标。Replica 把这个想法落到实处——取一篇已发表论文，选中正文里的一张结果图，从 PDF 中移除，剩下的工作就是把那张图背后的实验重新搭起来。任务的构造本身也是一条视觉—语言流水线：先扫描定位正文中每一张结果图及其图注，再在一个由 LLM 验证器把关的修复循环里框出边界框，最后把该图不可逆地涂除。因为抹除不可逆，agent 无法靠读原始 PDF 把答案捞回来。评分所用的 rubric 由 LLM 在看不到原图的前提下逐任务生成，因此 rubric 描述的是「一次正确的复现必须证明什么」，而不是「目标图长什么样」。作者随后用改造过的 GRPO 在这个任务空间上后训练 Faraday，并在留出集上与前沿基线对比。

## Tasks

**310 个图复现任务**——**242 个训练、68 个测试**——取自 **1990 至 2026 年间发表的 100 篇** 机器学习与 AI for science 论文。每篇论文贡献 **1–13 个任务（中位数 2）**，并经过人工质量筛选。任务生成的三个视觉—语言阶段均由 Gemini 2.5 Pro 驱动。测试集把同分布的 ML 任务与分布外的 AI for science 任务分开，因此跨分布的泛化是直接测出来的，而不是假定的。

## Domains

**AI & Machine Learning Research。** 源论文是机器学习与 AI for science 的出版物，复现目标则是一张机器学习结果图——训练曲线、消融、benchmark 对比——通过重跑背后的实验来还原。AI for science 子集确实涉及 ML 的科学应用，但论文没有给出该子集的分领域构成，因此不指派任何科学类共同领域。

## Evaluation

评分由自动生成的 **rubric 评判器**完成。Claude Opus 4.7 依据一份人工设计的元提示逐任务撰写 rubric，且撰写时看不到原图，涵盖**五个维度**：视觉吻合度、科学论断支撑、实验实现、算力预算使用、科学诚信。

评判器质量以 Kendall τ 对照人类评分者报告（**n = 20**，均为在 ICML/ICLR/NeurIPS 有论文的博士，共 **117 次排序**）。rubric 评判器与人类的一致性为 **τ = 0.19**，基线评判器为 **τ = 0.15**——但更能说明问题的是自洽性：rubric 评判器两次独立采样之间一致性达 **τ = 0.66**，基线评判器为 **τ = 0.46**，而**两位人类之间只有 τ = 0.30**。训练阶段每条 rollout 采样三次评判；采样八次做平均可把噪声压到基线评判器采样三次的水平。

在留出集上，Faraday 在 **73%** 的同分布 ML 任务和 **60%** 的分布外 AI for science 任务上同时胜过 Claude Opus 4.8 与 GPT-5.5，平均比 Claude 高 **6%**、比 Codex 高 **8%**。在人类偏好研究中，评分者在所考察的 **41 条 rollout 中有 29 条**更偏好 Faraday。

## Typical Duration

每个任务 **60 分钟墙钟时间**，算力为 **一张 H200 的七分之一 MIG 切片**，**每轮上下文窗口 16K token**。Faraday 自身使用 128K token 上下文，通过 shell 包装器调用编码 agent，可以并行拉起多个实例，也可以重置它们的上下文。

## Main Contribution

一个靠自动生成而非人工策划搭起来的复现任务空间——图一旦可抹除，任何合适的论文都能变成任务——配上一个自洽性高于人类之间一致性的 rubric 评判器，并证明用这份信号后训练一个 27B 模型，就能在留出复现任务上胜过大得多的前沿模型。

## Key Design Ideas

- 图的抹除不可逆，目标无法从输入中还原，于是任务不可能靠从原 PDF 里抽取信息蒙混过关。
- rubric 在看不到原图的条件下生成，避免评判器过度盯住目标图那些无关紧要的视觉细节。
- 评判器不只对照人类，还报告自洽性；论文明白写出两位人类之间的一致性（τ = 0.30）低于评判器两次采样之间的一致性（τ = 0.66）。
- Faraday 把编码 agent 当作工具，而不是自己重新实现编码能力，因此后训练学到的是研究方向的把握，而非代码生成。
- 分布外的 AI for science 测试集与同分布 ML 测试集分开保留，跨分布迁移单独报告。
- 每个任务的算力刻意压得小且固定（一个 MIG 切片、60 分钟），既限定了任何 agent 能尝试的上限，也让 rollout 便宜到可以拿来训练。

## Strengths

- 评分目标来自 agent 看不到的已发表论文，成败因此锚定在外部结果上，而不是 agent 自己的输出或一个无参照的评判器。
- 任务构造全程自动，这正是 100 篇论文能产出 310 个任务的原因，也让这个空间有明确的扩展路径。
- 评判噪声是测出来的而非假设的，而论文报告了一个并不体面的发现：它请来的人类评分者彼此之间的一致性，还不如评判器与自己的一致性。
- 1990–2026 的发表年份跨度远大于多数复现 benchmark 所取的近期 arXiv 窗口。
- 人类偏好是由合格评分者在真实 rollout 上收集的，而不是让众包人员对摘要打分。
- 论文报告了不利于自身论点的失败案例——Faraday 在若干作者相信原结果扎实的论文上失手。

## Limitations

- 论文没有给出公开发布位置，只提供了一个联系邮箱，因此这个任务空间目前无法被他人复用（上文记为 `TODO(reference)`）。
- 与人类的一致性绝对值很低（τ = 0.19）。作者的辩护是人类之间的一致性本身也低——这论证的是天花板低，而非评判器好。
- rubric 评判器未在大规模任务上验证过，作者也说明人类偏好研究不足以支撑平均意义上的结论。
- 所有任务都是纯计算任务，且受 60 分钟、单 MIG 切片的预算约束，因此需要可观算力或任何物理实验的结果，从构造上就够不着。
- 作者明确承认复现类 benchmark 普遍存在的构念效度问题。
- Repository note: 论文的主打贡献是后训练出的 agent Faraday。本卡片把 Replica 及其评判器当作可复用的评估工件，这一取舍是本仓库的；工作的训练那一半不在本仓库范围内。
