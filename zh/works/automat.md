# AutoMat (2026)

> [English](../../works/automat.md) | **简体中文**

## Overview

AutoMat 是一个评估基于 LLM 的编码智能体能否端到端复现计算材料科学论文中论断的基准。它包含 85 条专家精选的论断，在代表现代 HPC 工作流的资源受控环境中执行，表现最好的智能体配置在其上取得 54.1% 的成功率。

## Summary

作者指出，编码智能体在软件工程基准上表现强劲，但这种成功能否迁移到计算科学工作流尚不清楚——后者要求驾驭领域特定的流程，并结合科学论断解读结果。AutoMat 将领域专家从计算材料科学论文中精选的 85 条论断打包为可运行任务：智能体必须恢复计算流程、用专业工具链执行，并给出支持或推翻该论断的证据。在五种智能体设置中，最强配置 Claude Code 搭配 Claude Opus 4.6 取得 3.52 的平均可复现性得分与 54.1% 的成功率，而当工作流必须仅凭论文文本重建时，所有系统的成功率都接近于零。

## Tasks

85 项论断复现任务，按所需流程恢复程度分为三类：from-paper reproduction（依靠源论文描述的通用工具与公开资源）、from-artifact reproduction（依赖对复现路径必不可少的定制代码库、预训练模型或数据集）与 from-artifact interpretation（对提供的模拟输出做事后分析）。领域专家（SME）——已以第一作者身份发表至少一篇同行评审材料科学期刊论文的资深博士生与博士后——挑选以论文关键证据性数值结果为中心的论断，为其标注来源、预期结果以及对智能体隐藏的分步复现流程；每项任务打包论断文本、源论文、元数据文件与可选工件。

## Domains

计算材料科学，涵盖统计/机器学习方法、密度泛函理论、分子动力学与离散位错动力学。

## Evaluation

- **Overall reproducibility score.** 一个独立的基于 LLM 的评估智能体——获得 SME 标注的真值复现步骤、可用时的参考代码、论断、论文与完整执行轨迹——给出从 5（完全复现）到 1（失败）的五级评分；与固定提示词的裁判不同，它可以浏览工件目录、检查文件并使用工具。
- **Success rate.** 得分不低于 4 的运行占比，并在方法保真度、执行能力、结果准确性、完整性与科学严谨性五个维度上给出分维度评分。
- **Judge calibration.** 在由合格 SME 盲评的 40 次分层抽样运行上，评估器达到 0.69 的二次加权 kappa 与 0.80 的相差一分以内准确率。
- **Reported.** 在五种设置中，Claude Code 搭配 Claude Opus 4.6 最强，平均得分 3.52、成功率 54.1%；Codex CLI 搭配 GPT-5.4 最弱，为 2.44 与 23.5%；from-paper reproduction 是迄今最难的类型，各系统平均得分仅 1.5–2.2 且成功率接近于零，而 from-artifact reproduction 的平均得分为 3.1–4.1，成功率介于 39% 与 77% 之间。

## Typical Duration

论文未给出每任务的步数或 token 预算；实验设置与运行环境附录仅规定硬件层面的限制。作业在 Slurm 管理的节点上运行，上限为 96 个 CPU 核心，统计/机器学习类论断配有 NVIDIA A100 GPU，除非另有说明，最大挂钟时限为 72 小时。

## Main Contribution

一个由 85 条 SME 精选计算材料科学论断构成、用于评估 LLM 智能体端到端科学可复现性的基准，既作为可复现性基准，也作为诊断智能体系统在 AI-for-science 场景中失败环节的工具。

## Key Design Ideas

- 以论断为任务单元：每项任务打包论断、源论文、元数据文件与可选工件，SME 撰写的复现流程保留用于评估并对智能体隐藏。
- 按需要恢复流程的多少划分三种复现类型，并与五类验证方式交叉：标量指标匹配、比较/排序、结构/定性、区间/界限验证与图形复现。
- 在代表现代 HPC 工作流的资源受控环境中执行，预装包括 Quantum ESPRESSO 与 LAMMPS 在内的模拟软件栈。
- 评估器本身也是智能体：它借助工具从产生的工件目录与执行轨迹中收集证据，并在同一五级量表上与盲评 SME 打分进行校准。

## Strengths

- 论断来自真实论文，由拥有第一作者材料科学论文的研究者精选，瞄准作为各论文结论关键证据的数值结果。
- 三种任务类型区分失败来源：从文本恢复欠明确的工作流、改造提供的工件，以及判断既有输出是否真正支持论断。
- 完整保留轨迹——日志、命令、中间输出与报告——支撑失败模式分析，该分析发现流程不完整与方法偏离是最主要的错误。

## Limitations

- Repository note: 作者说明覆盖范围为来自单一（尽管宽泛）领域的 85 条论断，论断类型分布反映专家数据收集的现实条件，且基准只包含已被认定可复现的论断，因此无法测试智能体能否识别不可复现的论断。
- Repository note: 评分依赖一个 LLM 评估智能体，作者将其描述为对专家评估的可扩展近似而非替代；除最佳与最差配置外，其余设置的精确得分仅见于图中而未在正文给出。

## Related Works

- [ScienceAgentBench](./scienceagentbench.md)——同样从同行评审论文中精选任务并经领域专家校验，但将每项任务统一为一个自包含 Python 程序、以程序与输出层面的指标打分，而非由基于工件的 LLM 评估器裁定端到端论断复现。
- [Aviary](./aviary.md)——同样面向语言智能体的多步科学任务，但提供用于在分子克隆、科学文献研究与蛋白质稳定性工程上训练智能体的 gymnasium 环境，而非一组固定的专家精选复现论断。
