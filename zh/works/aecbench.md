# AECBench (2026)

> [English](../../works/aecbench.md) | **简体中文**

## Overview

AECBench 是一个面向建筑、工程与施工（AEC）领域的分层中文知识 benchmark：4,800 道由工程师命制的题目，按五级认知框架组织为 23 项任务，开放式作答由 LLM judge 依专家评分细则打分，并配有一道校准步骤来修正实测到的 judge 偏差。

## Summary

作者认为，AEC 工作事关安全、且由规范约束，一个笼统的总准确率说明不了 LLM 在实务中是否可信，能力必须按认知层级拆开来看。AECBench 因此把 23 项源自实务的任务沿五个层级排开——知识记忆、知识理解、知识推理、知识计算与知识应用，其中应用层再细分为分析、评价与创作。客观题按准确率计分；开放式题目——最长可达约 2,000 字的工程文档——则由 LLM-as-a-Judge 依领域专家预先设定的评分细则打分。论文没有把这个 judge 当成不容置疑的判准，而是当成研究对象：先量出它相对专家评分的偏差，再拟合回归模型加以校正。

## Tasks

23 项任务共 4,800 道题。知识记忆（3 项任务）：规范条文检索、术语、缩略语。知识理解（3 项）：规范解读、设计识图、表格数据理解。知识推理（3 项）：设计决策、建筑类型推断、表格推理。知识计算（4 项）：建筑设计、机电（MEP）设计、施工、工程经济。知识应用（10 项）：分析（5）、评价（2）、创作（3）。题目有两个来源——一支跨专业的领域工程师团队自行命制的题，以及取自官方执业资格考试的题——并经两轮审核：先作初步内容审查，再由从业十年以上的工程师作专家评审。作答形式随层级变化：低层级以选择题为主，高层级则用分类、抽取与开放式生成，创作类任务要求写出约 2,000 字的文档。题目为中文。

## Domains

土木与结构工程：题集扎根于建筑规范与规范表格、结构与抗震设计、混凝土结构、施工实务与工程经济。建筑设计与机电设计的内容属于 AEC 建成环境范畴的一部分，按本仓库的分类折入同一个领域；未指派第二个领域。

## Evaluation

- 客观题（选择、分类、抽取）对照参考答案按准确率计分。
- 开放式作答由 LLM-as-a-Judge 依领域专家预设的评分细则打分，而不是比对参考文本。
- judge 经过校准：未校准时它会系统性地压缩分数区间——专家判为 0–2 分的作答，它平均给到 4.25/10；专家判为 8–10 分的，它平均给 7.96/10。用保序回归与分段线性回归校准后，相对专家评分的平均绝对误差从 2.947 降到约 1.93–2.02。
- **报告。** 共评测九个 LLM，包括 DeepSeek-R1、DeepSeek-V3、GPT-4o、GLM-4-Plus、Qwen-Turbo、QwQ-32B、Moonshot-v1-128k 与 Hunyuan-TurboS。DeepSeek-R1 在 23 项任务中的 14 项领先。成绩沿五个层级单调下滑：术语记忆的准确率超过 95%，而在创作类任务上，每个模型的平均分都不到 60%。论文的结论表述是，尽管模型在记忆与理解层面已相当熟练，却「表现出显著的能力缺口，尤其是在解读建筑规范中的表格知识、执行复杂推理与计算，以及生成领域专业文档方面」。

## Typical Duration

N/A — 单轮问答与文档生成；未报告轨迹、wall-clock 时间或 token 预算。

## Main Contribution

一个面向 AEC 领域、以认知层级切分的知识 benchmark，题目取自从业者命制与执业资格考试；同时给出一套评测协议，把开放式工程文档上的 LLM judge 偏差量化并加以修正，而不是默认 judge 可靠。

## Key Design Ideas

- 五个有序认知层级把一个总分变成一条衰减曲线，失败点因此可以定位到某个认知阶段，而不只是某个主题。
- 应用层再拆成分析、评价与创作，其中创作要求写出完整篇幅的工程文档，而非简答。
- 开放式题目的判分依据是专家预设的评分细则，而非标准参考文本。
- judge 的输出经保序回归与分段线性回归重新校准到专家分数尺度，校准收益以误差降幅的形式报告。

## Strengths

- 题目由从业十年以上的执业工程师命制与审核，并辅以官方执业资格考试材料。
- 明确测量 LLM judge 相对专家评分的偏差，并报告校准后的残余误差。
- 发表于同行评议期刊，代码与数据集均公开。

## Limitations

- 不具 agent 属性：单轮问答与文档生成，无工具、无环境、无多步执行。
- 题目为中文，且锚定中国国家规范；能否迁移到 Eurocode、ACI、AISC 或 ASCE 的实务体系未经检验。
- 该 benchmark 衡量的是知识与文档生成，而非经过验证的工程结果——没有任何一个答案交给求解器或规范符合性审查引擎核对。
- Repository note: 论文报告了各认知层级的任务数，但未把 4,800 道题按层级拆分列出。
