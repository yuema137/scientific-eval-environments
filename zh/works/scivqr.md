# SciVQR (2026)

> [English](../../works/scivqr.md) | **简体中文**

## Overview

SciVQR 是一个多模态科学推理 benchmark，含 3,254 道配图问题，覆盖 6 个学科、54 个子领域——数学、物理、化学、地理、天文与生物——其中天文是单独计分的一等学科，并有自己的子领域划分。

## Summary

SciVQR 追问的是：多模态大语言模型能否完成那种真正依赖图示、图表、公式或结构图的科学推理，而不是仅凭文字就能蒙对。题目取自科学竞赛、大学入学考试，以及大学与研究生阶段的考试和教材，再经筛选，只保留视觉信息不可或缺、而非可有可无的题。除最终答案的准确率之外，benchmark 还为其中相当大一部分题目配了专家撰写的分步解题过程，并据此评判模型思维链的忠实程度。15 个开源与闭源 MLLM 在零样本下受评，分别测试有无 CoT 提示两种设定。

## Tasks

3,254 组图文问题对（每题一图），来自 15 项科学竞赛、9 种大学入学考试，以及 6 种大学或研究生阶段的考试与教材。组成上：2,545 道多项选择（78.2%）、709 道自由作答（21.8%）；1,490 道（45.8%）附有专家撰写的解析；2,661 道为英文（81.8%）、593 道为中文（18.2%）。难度分三档：容易 997 道、中等 1,240 道、困难 1,017 道。构建过程：20 余名研究生标注者对含图题目截屏，用 Mathpix OCR API 抽取文字，形成约 5k 题的初始题池，再按词面重合度与 Levenshtein 距离去重；子领域标签先由 GPT-4V 依预定义清单提出，再由人工复核修正，难度则沿用原始素材的标定。问题平均长度 77.2 词（最长 495），解析平均长度 102.4 词（最长 782）。

## Domains

六个学科：数学、物理、化学、生物、地理与**天文**。天文是六个一级学科之一，在结果表中占有自己的计分列，并列出六个子领域——天体物理、宇宙学、恒星天文、星系天文、行星科学与观测天文。共同领域即其余各学科：数学、物理、化学、生物，以及地球科学（论文中的「地理」学科，其子领域包括地质学、地貌学、水文学、气候学与制图学）。

## Evaluation

- 零样本准确率，按总体与分学科报告，采用两种提示格式：直接作答与 CoT 提示作答。主结果表报告的是 CoT 设定；另有一张表逐学科对比开启与关闭 CoT，第三张表按容易/中等/困难分层给出结果。
- 另有一项推理质量评估，把生成的思维链与专家撰写的解题过程对照，在五个维度上打分——忠实性、信息量、冗余度、幻觉与缺失步骤——每项 10 分制，取平均得到总分。自动评判由 GPT-4o 担任，在 SciVQR 的一个子集上进行；子集规模未说明（`TODO(reference)`）。
- **报告。** 共评估 15 个模型：11 个开源（LLaVA-NeXT-7B、LLaVA-OneVision-7B、MiniCPM-o-2.6-8B、Molmo-7B-D-0924、InternVL3-8B/14B/78B-Instruct、Qwen2.5-VL-7B/72B-Instruct、Keye-VL-1.5-8B、MiMo-VL-7B-RL-2508）与 4 个闭源（GPT-4o、o1、o4-mini、Gemini-2.5-Flash）。o4-mini 与 Gemini-2.5-Flash 并列总分最高，均为 79.3%，其后是 o1 的 77.2% 与 GPT-4o 的 60.7%。开源阵营最强的是经推理调优的 MiMo-VL-7B-RL-2508，为 69.2%；Qwen2.5-VL-72B-Instruct 61.8%，Keye-VL-1.5-8B 59.7%；最小的几个模型仍在 40% 以下。数学与物理是最难的学科；o4-mini 在每个学科上的准确率都超过 70%。CoT 提示对多数模型有帮助（Qwen2.5-VL-72B 总体 +7.9，GPT-4o +6.1，Keye-VL-1.5-8B +16.3），但对 InternVL3-8B 略有拖累（-1.1）。在推理质量细则上，o4-mini 总分 7.7、o1 为 7.2，而 Qwen2.5-VL-72B 为 5.2。
- 天文的分学科准确率此处不予引用，原因见 Limitations。

## Typical Duration

N/A — 静态单轮问答，无工具使用、无环境交互，也不设步数或 token 预算。实验在内部的 NVIDIA A800 GPU 集群上运行；未报告逐题的 wall-clock 或 token 成本。

## Main Contribution

作者把 SciVQR 定位为第一个同时具备三项性质的多模态科学推理 benchmark，而他们认为此前工作只做到了其中一部分：学科覆盖广（6 个学科、54 个子领域，对比 ScienceQA 的 5/41 与 MMMU 的 5/39）；难度跨度大，从高中一直延伸到研究生水平的多跳推理，而不是在 K-12 或大学层面就饱和；以及解题过程可追溯——分步的专家标注让细粒度的 CoT 评估成为可能。中英双语覆盖则被作为第四条轴，可用于跨语言研究。

## Key Design Ideas

- 只选取视觉信息不可或缺、而非可有可无的题目，以此压制语言先验与纯文本捷径。
- 45.8% 的题目配有专家撰写的分步解答，使过程评分能够独立于答案评分。
- 一套五维 CoT 细则（忠实性、信息量、冗余度、幻觉、缺失步骤），由 LLM judge 对照参考解题过程按 10 分制评分。
- 难度沿用原始素材的标定，而非事后指派，因而得到的三档分层可用于饱和度分析。
- 子领域标注分两步：先由模型从预定义分类体系中提出标签，再由人工复核修正。
- 中英双语的构成（81.8% 英文、18.2% 中文）使跨语言比较可以在同一个 benchmark 内完成。

## Strengths

- 天文是货真价实的一级学科，有明确的六个子领域分类和自己的计分列，而不是顺手借来当视觉测试台的附带数据。
- 答案准确率与推理过程质量分开测量，模型无法靠在选择题上猜答案而显得称职。
- 模型阵容宽（15 个系统，横跨不同参数规模，开源闭源兼有），且采用统一的零样本协议。
- 开关 CoT 的对比逐学科隔离出显式推理的贡献，而不只是给出一个总体数字。
- 难度分层呈现出预期中的单调退化，支持了这三档确有意义的说法。

## Limitations

- 这套 benchmark 只评估静态的多模态问答；没有 agent、没有工具使用、没有执行、也没有多步环境交互，因此它说明的是科学推理能力，而非 agent 行为。
- 未公布分学科的题目数量，因此 3,254 道题中天文部分究竟有多大并不清楚（`TODO(reference)`）。
- 推理质量细则所用子集的规模未说明，且 GPT-4o 既是评判者，又是被评估的模型之一。
- 子领域标签源自 GPT-4V 的提议；论文称经过人工复核，却未给出任何标注者间一致性统计。
- Repository note: 主结果表与 CoT 消融表的分学科列顺序不同（生物/地理/天文 对 天文/地理/生物），而共有行上的数字完全相同，因此仅凭已发表的论文无法无歧义地读出天文的具体准确率。总体数字与跨模型比较不受影响。
