# The Replay Gap (2026)

> [English](../../works/the-replay-gap.md) | **简体中文**

> **首次公开：** 2026-08-08 · **来源：** [arXiv 首次提交](https://arxiv.org/abs/2608.08239)

## Overview

一项评估方法学研究，表明为多步 LLM agent 中的逐步模型路由/切换打分的标准做法——回放一条已记录的轨迹并替换进另一个模型的历史输出——所测量的是一个不会发生的反事实世界，并提出以带匹配同模型对照分叉的分支（反事实）rollout 作为可靠的替代方案。

## Summary

LLM 路由器旨在用最便宜且够用的模型服务每个请求，并越来越多地被逐步应用于多步 agent 内部；然而 agentic 路由器常被当作单轮路由器来评估：回放已记录的轨迹、替换进另一个模型的历史输出，同时假定轨迹的其余部分保持不变。本工作用分支 rollout 直接检验这一假设——在受控点处分叉活跃的 SWE-bench agent 轨迹、重建环境，并用不同模型继续每个分叉——并把「替换」与匹配的同模型对照分叉相比较，后者用于隔离采样与回放噪声。在六组配对运行（约 900 次 rollout）中，模型替换以很大幅度偏离其匹配的对照基线，并改写了随后的多数动作，而一个日志拼接式回放评估器对每一个与成败相关的结果都预测错误。作者得出结论：基于回放的 benchmark 对 agentic 路由「给错世界打了分」，并公开了他们的 harness 与轨迹数据。

## Tasks

并非任务 benchmark，而是建立在既有 benchmark 之上的方法学/测量研究。底座是用 mini-SWE-agent 脚手架（一个仅用 bash 的 ReAct 循环）运行的 SWE-bench Verified 软件修复实例，采用 50 步预算与 28k-token 上下文，并使用官方的逐实例 Docker 镜像。实验由六组配对运行（三个难度档上正向/反向的切换方向）构成，共约 900 次 rollout、覆盖 717 个被评分的分支对，每组运行对含 30 个实例、359 个同模型对照分叉。基线轨迹在受控深度（报告为轨迹长度的 30% 与 70%）处分叉：「对照分叉」用同一模型继续，以隔离采样与环境回放噪声，而「替换臂」用另一个模型继续，以测量路由的反事实。模型：一个小模型（Qwen3-4B-Instruct，FP8 量化）与一个大模型（Qwen3-14B，AWQ 量化），通过 vLLM 在单张 24GB GPU 上以温度 0 提供服务。

## Evaluation

分叉与其基线/对照之间的偏离，用分叉后动作序列的归一化编辑距离来度量，另加被改写的分叉后动作比例、在第一个分叉后动作即偏离的分叉比例，以及仍然有效的被回放状态比例。用经多重性校正的 95% 置信区间来检验替换效应是否超过匹配的对照基线。任务成败采用 SWE-bench 结果（实例解决/未解决），并追踪替换与对照之间的「结果翻转」。一个日志拼接式回放评估器通过与切换实际产生的补丁的相似度，与活跃 rollout 相比较。

## Main Contribution

论文认为，对 agent 中逐步模型切换的静态/回放评估并不可靠，因为被替换的模型会改变下游轨迹，日志拼接因而对一个从未运行过的世界打分。它引入带匹配同模型对照分叉的分支反事实 rollout，把偏离归因于替换（相对于采样与回放噪声），并量化由此产生的「回放差距」，表明回放会对与成败相关的结果做出错误预测。

## Key Design Ideas

- **分支 rollout。** 将一条基线轨迹执行到底，然后在新容器中于受控深度处重新分叉，先回放分叉前的动作再继续。
- **匹配对照分叉。** 用同一模型继续，以隔离采样非确定性与环境回放漂移，为归因提供逐条件的噪声基线。
- **替换臂 vs. 对照基线。** 替换引起的偏离以其相对匹配对照基线的超出量来判定，并用经多重性校正的置信区间。
- **直接的回放评估器审计。** 用与切换实际产生补丁的相似度、以及对与成败相关结果的判定，为日志拼接式回放评估器打分，对照活跃分支结果。
- **对「确定性」的噪声基线审计。** 温度 0 的确定性按服务栈（FP8 vs. AWQ 量化）逐一检查，而非默认假定。

## Strengths

- 用一套活跃、能重建环境的 harness 而非仅凭论证来经验性地检验回放假设，并用同模型对照隔离出替换效应（六组配对运行、约 900 次 rollout、359 个对照分叉）。
- 替换以 +0.25 到 +0.66 的归一化编辑距离超出其匹配对照基线（经多重性校正的置信区间不含零），并改写 61–94% 的分叉后动作；74–77% 的早期替换在第一个分叉后动作即偏离，而对照仅为 6–35%，早期分叉后仅约 3% 的被回放状态仍有效。
- 观测到的全部五次结果翻转都发生在替换臂中（升级挽救了未解实例，一次降级丢掉了唯一的解），359 个对照分叉中一次都没有，把方法学论点与影响成败的后果绑定起来。
- 直接的评估器审计：回放评估器所预测的补丁与切换实际产生的补丁相似度为 0.00–0.11，且对每一个与成败相关的判定都预测错误。
- 揭示了一个服务栈混杂因素：FP8 服务的对照在温度 0 下有超过 90% 的分叉发生偏离，而 AWQ 服务的对照偏离远少，表明「确定性」依赖于配置。
- 公开了 harness（GitHub）与轨迹数据集（HuggingFace）以供复用。

## Limitations

- Repository note: 研究只用一种 agent 脚手架（mini-SWE-agent）与一个 benchmark（SWE-bench Verified）、两个特定量化模型（Qwen3-4B FP8、Qwen3-14B AWQ），因此回放差距在其他脚手架、任务或模型对上的量级并未由这些证据确立。
- Repository note: 分叉取自两个受控深度（约 30% 与 70%）、温度 0；在其他深度、采样温度或步数/token 预算下的行为不在所报告的设定内。
- Repository note: 偏离主要以动作序列编辑距离与补丁相似度来度量；这些是行为差异的代理指标，本身并不量化路由的下游成本或效用。
