## Overview

PATH-Bench 是面向终身 LLM agent 的路径依赖评估 benchmark：它构造迁移关系已知的受控任务序列，度量累积经验的*顺序与内容*——无论存成可检索的记忆还是可复用的 skill——如何改变一个骨干冻结的 agent 迁移什么、保留什么、遗忘什么。

## Summary

终身 agent 的适应方式，是把过往交互写进冻结骨干之外的外部学习状态；但 benchmark 通常只跑固定或随机打乱的任务流，无法揭示经验的*路径*如何塑造后续表现。PATH-Bench 做了两处替换：用一个估计出来的任务关系矩阵引导采样，代替对历史的穷举枚举；用对单个反复出现的探针任务做纵向追踪，代替对整套任务的反复重测。它报告一个总体指标（Average Performance）与三个学习动力学指标（前向迁移、后向迁移、遗忘），全部只从探针轨迹上读出；并评估了八个终身 agent，涵盖检索增强生成、agentic 记忆与 skill 累积三类。作者另外提出 Selective Experience Use（SEU）——一套 agent harness，它会筛选哪些累积条目可以影响新任务。

## Tasks

两个任务池，交互结构刻意不同：BigCodeBench（单轮程序合成，指令复杂、函数调用多样，按任务是否完成计分）与 WildToolBench（多轮、跨工具的规划与执行，按成功完成的子任务比例计分）。按「留有上升空间」的原则，基座 LLM 已经做满、或看不出明显学习信号的任务被筛掉，每个 benchmark 各采样 D = 120 个任务组成评估池。任务之间的有向关系用单样本上下文迁移增益矩阵 M(i,j) = S(t_j | t_i) − S(t_j | ∅) 估计，由 DeepSeek-V4-Flash、GPT-5.4-mini 与 GLM-5.0 分别独立计算（各五个随机种子）；每个模型就其平均增益的符号投一票，至少两个模型一致时该关系才被确定，正负各得一票的任务对标为 mixed 并排除在外。采样器据这张投票矩阵搭出以探针为中心的序列：五个任务的正迁移预热、100 个任务的介入队列（探针间隔 6–12），且介入任务中有 70% 取自该条件下占主导的（正或负）迁移集合。每个数据集、每种条件各采样五十条终身评估序列。

## Domains

通用 agent 场景——程序合成与多轮工具使用。不针对任何规范科学或工程领域；受评对象是经验累积的路径依赖性，而非某个领域任务。

## Evaluation

只有介入任务会更新 agent 的外部学习状态；探针任务的每次重复只作为测量点，因此探针成绩的变化恰好把累积历史带来的促进与干扰分离了出来。Average Performance（AP）是序列中所有任务执行成绩的均值。前向迁移（FWT）是第 3 至第 n 次探针相对冷启动探针得分的平均增益；后向迁移（BWT）取相对预热后参考得分的增益，只留正部再求平均；遗忘（FGT）取低于该参考得分的缺口，同样只留正部再求平均。每条序列跑五次，所有受评 agent 都以 DeepSeek-V4-Flash 作为基座推理模型。参与比较的八个 agent 为：BGE-M3 RAG 与 HippoRAG-v2（检索）、Clin、AWM、SimpleMem 与 MemRL（agentic 记忆），以及 AutoSkill 与 SkillClaw（skill 累积）。

## Typical Duration

一条终身序列由五个预热任务、100 个任务的介入队列，以及按 6–12 间隔穿插其间的探针重复执行构成；论文报告的探针动力学分析覆盖五十条序列共有的前十二次探针。未报告墙钟时间或 token 预算。逐任务成本为 `TODO(reference)`。

## Main Contribution

作者称 PATH-Bench 是据他们所知第一个在*受控*历史下追踪 LLM agent 迁移与保留的 benchmark：用多模型上下文学习估计任务关系，采样可配置的、受关系约束的序列，并量化由此产生的成绩变化；此外还给出一项针对八个终身 agent 的受控实证研究，把外部学习状态、状态的表示形式与学习路径三者拆开。

## Key Design Ideas

- 以探针为中心的序列：纵向追踪单个反复出现的探针任务，而不是反复重测整套任务，使路径依赖分析在 LLM-agent 的规模上仍然负担得起。
- 用单样本上下文迁移增益作为任务两两可迁移性的廉价代理，配三模型符号投票，并剔除信号混杂的任务对。
- 正迁移主导与负迁移主导两种历史条件，均从同一个任务池搭建，于是干扰与促进是被操纵出来的，而不是被动观察到的。
- 严格区分会更新状态的任务（介入任务）与用于测量的任务（探针重复）。
- 一次无记忆的骨干运行充当基线，每个携带经验的 agent 都以它为参照计分。
- 受控的路径转换序列（X → I1 → X → I2 → X，探针匹配、间隔五个任务）把近期经验与更早经验的影响分离开。

## Strengths

- 把学习路径的构成变成一个实验变量，而不再是不受控的混杂因素，并证明同一套任务上的不同路径可以改变 agent 的排名次序。
- 在同一套协议、同一个骨干之下，覆盖了三类结构截然不同的外部学习状态（检索、agentic 记忆、skill 累积）。
- 上升空间筛选剔除了已做满的任务，测出的差异因此不会被天花板效应压缩。
- 把迁移与保留分开：论文报告了强即时迁移与大量遗忘并存的情形（例如 HippoRAG-v2 在 BigCodeBench 的负迁移主导条件下取得最好的 FWT，7.03 个百分点，同时遗忘 16.15 个百分点）。
- 发现经验的有效表示形式取决于交互结构——以 skill 累积见长的 AutoSkill 在单轮的 BigCodeBench AP 上领先（正迁移主导条件下 73.93%，无记忆基线为 70.18%），而因果规则式记忆（Clin）在多轮的 WildToolBench 上领先。

## Limitations

- 只有两个任务池（一个单轮编码、一个多轮工具使用），agent 运行也只用了单一骨干模型，因此所报告的表示形式与交互结构之间的相互作用，建立在较窄的基底上。
- 迁移关系是用单样本上下文效应近似的，而非由实测的 agent 演化得出；论文明确把这作为一种实用代理来呈现。
- Repository note: 论文把一个 benchmark 与一套自行提出的 harness（SEU）捆在一起；可复用的评估工件是 benchmark 部分，而 SEU 的收益是在作者自己设计的同一套协议上报告的。
- Repository note: 所审阅的版本未给出代码或项目地址，序列采样器的可复现性因此无法从一手来源确认。
