# GeneBench-Pro (2026)

> [English](../../works/genebench-pro.md) | **简体中文**

## Overview

GeneBench-Pro 是一个面向 AI agent 的 benchmark，考察其在基因组学、定量生物学与转化医学中执行真实多阶段统计分析的能力。其 129 个问题构建于人工模拟的数据生成过程（DGP）而非真实数据集之上，从而使一个错误答案可归因于科学判断失误，而非归因于若干同样站得住脚的分析选择之一。

## Summary

作者指出，现有生物学 benchmark 大多从一个已整理好的数据集与高度具体化的 prompt 出发，评估的是范围狭窄、答案可干净验证的单个分析步骤，而真实分析所跨越的过程要宽得多、迭代性也强得多。GeneBench-Pro 把每个问题置于隔离容器中，配以刻意保留杂讯的模拟数据，以及一段只锁定目标估计量、不给出任何方法指令的极简 prompt，随后仅以二元通过与否判定 agent 是否复原了那个与决策相关的数值。在完整题集上，所测得的最佳配置 GPT-5.6 Sol（`max` 推理档）达到 28.7% 的 eval 级通过率。

## Tasks

129 项评测，覆盖 10 个主域与 21 个终端子域，核心落在基因组学。每个问题都由一个因果结构完全已知的模拟数据生成过程构造，并内含若干实质性的推断分岔——即一旦选错某个看似合理的选项，下游答案便会产生质变的决策点——每题 3 至 13 个不等，中位数为 6。该题集承自 GeneBench 的 103 个问题：其中 3 个因存在致命问题被撤回，余下 100 个中有 54 个经过大幅重新设计与加固，另新增 29 个。问题在挑选时刻意避开广为人知的教科书案例与论文，以免退化为对记忆解法的考核。

## Domains

统计遗传学与遗传流行病学、群体与演化遗传学、数量遗传学、调控与分子多组学、功能基因组学、蛋白质组学与生物标志物、临床变异解读与外显率、药物基因组学、产前与生殖遗传学、肿瘤体细胞基因组学与液体活检、微生物与宏基因组学，以及法医遗传学。

## Evaluation

- **对可复原目标的二元判分。** 采用预先设定的问题专属目标字段、精确匹配规则与绝对数值容差；只有当每一个受评字段都满足其约束时，该次运行才记为通过。ground truth 取自可从暂存文件复原的估计值，而非生成数据时所用的参数。
- **不设部分给分。** 主指标不设任何部分给分或诊断性计分通路，其理由是：一个中间步骤大多正确、但最终给出错误决策相关答案的 agent，并没有真正自动化这项分析。
- **通过率取 129 个问题各自通过率的非加权均值**，每个「模型—问题」对独立重试 10 次；GPT Pro（Extended）与 Claude Opus 的运行降为 5 次。
- **不确定性与剔除。** 95% 分层 bootstrap 置信区间，重采样 20,000 次，且同时对问题与问题内的重复运行做重采样；因容器、工具链、服务方或响应格式故障而剔除的运行占比不足 1%。
- **分层的次级报告。** 各问题通过率另按区间（0%、0–10%、10–50%、≥50%）汇报，并按发布子集与外部评审状态分别拆分——作者引入这一拆分，正是为了让选择效应保持可见。
- **报告：** GPT-5.6 Sol 在 `max` 推理档达到 28.7%，GPT-5.6 Sol Pro 在单独报告的 GPT Pro 运行中达到 31.5%；GPT-5.5 为 12.0%，GPT-5.4 为 8.9%，最强的非 GPT 基线 Claude Opus 4.8 为 16.0%。在 GPT-5.6 Sol 内部，通过率随推理档位从 `none` 的 3.7% 依次经 14.4%、22.5%、24.4%、26.8% 升至 `max` 的 28.7%。

## Typical Duration

评测框架未施加统一的 wall-clock 预算，也未规定步数上限；运行仍受评测栈中服务方与平台行为的约束。论文给出的唯一时长参照来自人类：其估计一个典型问题若由人类专家独立完成，全程约需 10–40 小时，并注明该数字仅作示意。

## Main Contribution

一种以模拟为根基的多阶段科学分析 benchmark 设计——数据生成过程是构造出来的而非借用现成数据，从而使判分既对邻近的、同样站得住脚的分析选择不敏感，又对缺失科学上必要的环节保持敏感。

## Key Design Ideas

- 完全模拟的数据生成过程，且 ground truth 定义为可从暂存数据复原的估计值而非生成参数，以免在抽样波动使该参数无法复原时，把正确的分析判为错误。
- 一段「最小可用 prompt」：只界定问题与受评估计量，不给出规定性的方法指令——作者认为正是这一点使任务不致退化为对既定分析流程的执行考核。
- 二元的全有全无判分，其取舍是贴合该分析所服务的下游决策，而非追求测量分辨率的最大化。
- 分层发布——10 个问题公开、50 个交由第三方作独立评测、其余作为内部保留集——作为一种显式的污染管理机制。

## Strengths

- 判分有效性是被工程化并经过审计的，而非默认成立：消融实验证明看似合理但错误的分析会以明显差距被判失败，质量控制方面的要求则确保邻近的合理阈值产出相同的判分结果。
- 对一次 benchmark 发布而言，统计报告的严谨程度不同寻常——非加权的逐问题均值、每对多次重试，以及同时对问题与运行做重采样的 bootstrap 区间。
- 评估完整性这一层是被记录下来而非仅作宣称：129 个问题中有 82 个经外部领域专家评审，论文原样复现了评审意见及其处置，其中包括评审者发现作者据以判分的 ground truth 本身有误的情形。

## Limitations

- Repository note: 二元判分抹平了阶段级的诊断信息——一次解决了大部分决策点但在后段失败的运行，与一开始就失败的运行得分相同——且逐问题的决策点计数只作为定性元数据保留，并未用于对性能作分层，因此该 benchmark 端到端地度量了其多阶段主张，却尚未按推断链长度报告性能。
- Repository note: 129 个问题中有 119 个未公开，故其头部榜单无法基于公开包独立复现；而论文自身的分层报告显示结果随发布子集显著变化——援引该 benchmark 的任何数字时，都应一并交代其所属分层。

## Related Works

- [ScienceAgentBench](./scienceagentbench.md) — 同样是面向数据驱动型科学分析的执行式 benchmark，但其任务取自真实的已发表工作；而这恰是 GeneBench-Pro 所反对的基础——理由是真实数据允许多条同样站得住脚的路径。
- [NatureBench](./naturebench.md) — 同样从已发表研究而非合成任务中获取科学难度；其难度来自文献的广度，而 GeneBench-Pro 的难度来自单个问题内一条人工构造的依赖决策链的深度。
- [Terminal-Bench Science](./terminal-bench-science.md) — 同样在无外网的沙箱容器中运行科学任务，但其难度相当程度上落在工具链与执行上；而 GeneBench-Pro 刻意把问题设计成不依赖已安装工具，以便把统计判断力单独隔离出来。
