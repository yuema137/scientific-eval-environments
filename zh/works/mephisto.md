# Mephisto (2025)

> [English](../../works/mephisto.md) | **简体中文**

## Overview

Mephisto 是一个多智能体 LLM 框架，它驱动 CIGALE 光谱能量分布（SED）代码，从多波段测光推断星系的物理性质，并借助树搜索与自我博弈积累的知识库不断改进物理模型。除框架本身外，作者还构建了一个 256 个星系的任务集，配以外部的定量通过判据，用全部七种 LLM 骨干各跑一遍，并把代码、星表与知识库发布在 Zenodo 上。

## Summary

Mephisto 把 SED 解释拆解成若干协作的 agent 角色——假设推理、CIGALE 执行、拟合评估、知识提取与知识校验——并在候选物理模型上搜索，而不是在固定的预计算参数网格上搜索。每个星系的分析都靠展开一棵模型改进假设的搜索树来完成（深度优先用于利用，广度优先用于探索），每次 CIGALE 运行的拟合质量都会反馈到下一轮推理；从过往交互中提炼的经验经消融验证后，留存进一个持久的知识库。作者在一个特意构建的 256 星系样本上评估该框架，样本取自 COSMOS2020，打分对照一个 3.6 亿点的穷举 CIGALE 网格；他们还把框架用于 JADES 中 31 个 JWST 发现的「小红点」（Little Red Dot）天体。跨骨干研究则用七种不同的 LLM 把 256 星系的完整流程各重跑一遍，报告成功率与相对 API 成本的关系。

## Tasks

每个任务就是一个星系：给定多波段测光数据，产出一个 SED 模型，其拟合质量要能与穷举网格搜索相当。主任务集含 **256 个星系**，取自 COSMOS2020 星表，并有 PRIMUS、3D-HST、SDSS 等巡天的光谱确认。这个样本不是顺手挑来的——作者在四维空间（红移、恒星质量、V 波段尘埃消光、恒星形成率）上拟合了一个 neural spline flow，再在其中均匀采样，因此样本覆盖 z = 0.1–5.7、M⋆ = 10⁶–10¹² M☉、A_V = 0–3 与 SFR = 10⁻⁴–10⁴ M☉/yr。第二个更难的应用集是 JADES 中 **31 个 JWST 发现的「小红点」星系**，学界对它们尚无共识的物理解释。做知识库消融时，作者把 256 个星系拆成 **208 个**用于知识积累、**48 个**留作未见过的测试星系；跨骨干研究用的是全部 256 个。论文没有为星系定义难度层级（它的三档分组是按 LLM 成本，而非任务难度）。

## Domains

**天文学**——具体是河外天文与星系天体物理。评测目标是一项天文推断：从多波段测光反推真实观测星系的物理性质（恒星质量、恒星形成率、尘埃消光、红移、AGN 贡献），所用的是天文专用建模代码（CIGALE）与真实巡天数据（COSMOS2020、JWST/JADES）。不指派共同领域：这项工作没有贡献通用方法学 benchmark，其软件部分也只是既有天文代码的一层薄封装，而非软件工程评测。

## Evaluation

通过判据在系统之外，且是定量的：只要 Mephisto 对某个星系产出**任意一个**满足 **χ² < 1.2 × χ²_baseline** 的 SED 模型，就判定它给出了合理的解释；其中 χ²_baseline 来自一次穷举 CIGALE 网格搜索，网格跨 10 个物理参数、共 **3.6 亿个格点**（在 Brown et al. 2014 式模板库的基础上扩展了红移范围与 AGN 占比）。次级的一致性指标只报告、不设阈值：解落在穷举搜索 χ² 值的 ±20% 以内，推断出的恒星质量与网格搜索值相差约 ±0.3 dex 以内。跨骨干比较沿用同一判据，其中多数模型的成功率达到 **80–90%**，而低成本档相对 GPT-4o 下降超过 25 个百分点。`TODO(reference)` — 逐模型的成功率数值只以图形呈现（图 10），正文未列成表格，因此七种骨干各自的确切数值无法引用。小红点分析不按公式打分，而是与已发表的人类专家分析做定性验证。

## Typical Duration

每个星系约 **36 步推理（已探索的搜索状态）**，每步生成 **N_b = 4** 个改进假设；小红点上的广度优先运行同样把已探索状态上限设为 36。每一步都要执行一个 10⁴–10⁶ 个格点、8–12 个自由参数的 CIGALE 网格，因此单个星系的完整分析约评估 **1×10⁶ 到 6×10⁶ 个模型——大致相当于 3.6 亿点基线网格的 1%**。以 GPT-4o 为骨干时，作者报告一次详细分析每个星系约 **200K token、约两美元**；中等成本骨干约为其 1/10，低成本骨干约为其 1/100。论文未报告单个星系的 wall-clock 时间。

## Main Contribution

按作者的表述，Mephisto 是首个模拟人类科学推理来解释多波段星系观测的多智能体 LLM 框架：它对接成熟的物理建模代码库，通过树搜索做审慎推理，借自我博弈积累知识，并更新自己的知识库。作者把它摆在「天文学中的黑箱机器学习方法」的对面，称其为透明、与人类对齐、可融入现有研究实践的替代方案，也是迈向端到端 AI 驱动科研工作流的一步——定位是「天文学家的科研副驾」，而不是一套评测。

## Key Design Ideas

- 五个协作的 agent 角色：推理 agent 提出模型假设，执行 agent 运行 CIGALE，评估 agent 判断各测光波段上的拟合质量，学习 agent 从交互历史中提炼经验，校验 agent 把关什么可以进入知识库。
- 搜索的对象是*物理模型*而非静态参数网格：每个节点是一个模型配置，展开时生成 N_b = 4 个候选改进，用深度优先搜索去利用有希望的方向，用广度优先搜索让备选的物理解释保持在案。
- 传统方法在这里是参照系而非竞争组件：3.6 亿点的穷举 CIGALE 网格定义了解必须逼近的 χ²，因此衡量 agent 的参照是既有实践，而不是另一个 agent。
- 自我博弈的知识积累带消融把关：从交互历史中提炼出 **72 条知识条目**，一条候选条目只有在「用它」与「不用它」的运行显示出可证实的改进时才会保留。
- 报告的记忆 / 知识效应：到推理深度 3 时，时序记忆带来约 25% 更大的改进（有记忆时相对 χ² 为 0.52，无记忆时为 0.67），外部知识库则在 48 个未见过的测试星系上把失败率降低 11%。
- 骨干扫描作为成本—性能研究：同一套 256 星系流程在七种 LLM 上重跑，分为高、中、低三个成本档（GPT-4o；DeepSeek-V3、DeepSeek-R1、QwQ-32B、DeepSeek-R1-Distill-Llama-70B；DeepSeek-R1-Distill-Llama-8B、GLM-4-Air-250414），并把成功率对相对成本作图。

## Strengths

- 通过判据锚定在系统之外的一件工件上——一次穷举 CIGALE 网格搜索——因此成功与否既不由 agent 自己的输出定义，也不由 LLM judge 定义。
- 256 个星系的集合是刻意构建来覆盖物理参数空间的（在四个性质上做基于 flow 的均匀采样），而非顺手拼凑，并且用的是经光谱确认的真实观测。
- 资源核算在天文 agent 论文里罕见地具体：每个星系的 token 数与美元开销、相对成本分档，以及以穷举基线网格占比表示的算力。
- 可复用的材料是公开的：Zenodo 记录（CC-BY-4.0 / MIT，2025 年 6 月）提供 agent 源码、COSMOS 与小红点的测光星表，以及知识库 JSON。
- 小红点研究把框架推到了真正开放的科学问题上——agent 独立地把文献中报告的两种竞争解释（尘埃遮蔽的星暴星系与被遮蔽的 AGN 宿主）都找了出来。
- 关于知识库的论断有受控消融支撑（有 / 无记忆、有 / 无知识、留出星系），而不是只作断言。

## Limitations

- 覆盖面只有一个任务族。每一个被打分的任务都是基于 CIGALE 的测光 SED 拟合；框架没有在光谱、成像、时间序列或其他任何天文推断上受过检验，因此报告的成功率无法推广到这一个工作流之外。
- 逐骨干的成功率只出现在图里，从未列成表格，因此七模型比较无法被数值引用（上文记为 `TODO(reference)`）。
- 成功是相对基线网格定义的，而不是相对真值。3.6 亿点的网格自身编码了模板库、先验与参数范围的选择；即便网格本身在某个星系上拟合得很差，该星系仍可能被判「通过」，而物理正确性只通过恒星质量的吻合做了抽查。
- 小红点结果——科学上最有意思的部分——靠与既往专家分析的定性比较来验证，没有定量的打分流程。
- 256 个星系没有难度分层，因此总体成功率无法分解成参数空间中容易与困难的区段。
- Repository note: 作者并未把这项工作呈现为 benchmark。论文中不出现「benchmark」与「test suite」两个词，第三节的标题是「Results」，通篇的定位都是科研副驾。本卡片把 256 星系集加上 χ² 判据当作一件可复用的评测工件；这一读法属于本仓库，而非作者。
- Repository note: 七模型研究是**同一框架内的骨干消融**，而不是不同 agent 系统之间的比较。它衡量的是 Mephisto 的脚手架换成更便宜的 LLM 还能跑到什么程度，至于其他 agent 设计在同一批星系上表现如何，它完全没有回答。
- Repository note: 参照点是**传统的 SED 拟合网格搜索**，既不是 agent 基线，也不是人类基线。任务集上没有评测任何竞争的 LLM agent。
- Repository note: 发布的是一份带版本号的 Zenodo 快照，而不是持续维护的评测框架——没有 runner，没有排行榜，也没有对外公开的留出划分。

## Related Works

- [Stargazer](./stargazer.md) — 最接近的对应物：在天文数据（径向速度时间序列）上做迭代式、以物理为依据的模型拟合，但它明确建成 benchmark 环境，带难度层级与逐判据反馈。
- [gammapyGPT](./gammapygpt.md) — 同样是 agent 驱动一套成熟的天文分析代码（Gammapy），并把数值输出与预期值核对，属于同一种「传统代码既当可执行环境又当参照」的模式。
- [ReplicationBench](./replicationbench.md) — 天体物理评测，参照的是已发表的专家工作而非网格搜索，任务与原作者共同开发。
- [AstroVisBench](./astrovisbench.md) — 天文工作流评测，落在代码与可视化一侧，与 Mephisto 的模型推断一侧互补。
- [Gravity-Bench-v1](./gravity-bench.md) — 物理发现评测，把算力 / 观测预算纳入打分，与 Mephisto 的成本对成功率报告可比。
- [SimulCost](./simulcost.md) — 面向模拟参数调优的成本感知评测，直接与传统方法对照，是同一种「单位算力精度」的框架。
