# SoM-1K (2025)

> [English](../../works/som-1k.md) | **简体中文**

## Overview

SoM-1K 是一个多模态 benchmark，收录 1,065 道经过标注的材料力学题目——每道题都由文字题干、示意图、一份专家撰写的图形描述，以及一份完整的标准解答配套组成——用来评测八个基础模型在三种 prompt 策略下的表现，判分全部由专家人工完成。

## Summary

材料力学是土木、机械、航空航天与材料工程课程体系的基石，解题时既要读题面，又要同时读懂示意图——支座形式、构件几何、荷载的作用位置与方向。作者据此认为它天然适合用来探测多模态工程推理能力，于是构建了一份把示意图当作一等标注成分、而非随手塞进 prompt 的图片的数据集。除原始示意图外，他们还引入 **Descriptions of Images (DoI)**：一份经专家核验、严格照实描述图中内容的文字，不含任何解题步骤，从而把视觉信息的贡献与推理提示的贡献分离开。在五个 LLM 与三个 VLM 上评测的结果是：最好的配置也只有 56.6% 的准确率，而且给了 DoI 的纯文本模型普遍胜过拿到真实示意图的视觉-语言模型。

## Tasks

1,065 道标注题目，按变形形式分为杆件轴向拉压（201，18.87%）、轴的扭转（137，12.86%）、梁的弯曲（630，59.15%）、刚架的弯曲（54，5.07%）与综合题（43，4.04%）；按静定性分为静定/简单（917，86.10%）与超静定/困难（148，13.90%）。题目内容涵盖内力、应力、应变与变形的计算，内力图绘制，以及面向设计的优化。题源是广泛使用的大学教材（中文版与国际版，含 Hibbeler 与 Gere & Goodno）以及从官方赛事网站获取的高水平力学竞赛题；综合题出自竞赛，把静力分析与振动、冲击、刚体运动结合在一起。构建流程为：教材扫描成 PDF，示意图人工提取为 PNG，题干与标准解答用 Doubao OCR 提取后再人工审校修正，解答中依赖图形的部分（如内力图）由标注团队手工补齐。因为模型在批量推理时对 LaTeX 处理不佳，LaTeX 公式经 DeepSeek-V3-0324 API 转成了自然语言描述。每道题有四个标准化组成部分：题干（PS）、图片（I）、图形描述（DoI）与标准答案（GT）。DoI 本身的生成方式是先让 Doubao VLM 写一版描述，再由标注团队订正其结构形式、边界条件、几何与荷载方向。标注团队由结构工程与材料力学方向的研究人员和教师组成——一名博士生、两名讲师、四名助教。

## Domains

土木与结构工程：该 benchmark 的主题是材料力学，本仓库的领域范围里已把它明确列在结构分析与结构建模之下；而占主导的题目类别正是结构分析中的受力构件——梁（59.15%）与刚架（5.07%）合起来占了数据集的大半，任务内容涉及内力、弯矩、挠度与超静定体系。论文出自土木工程院系（Hunan University College of Civil Engineering；University of Miami Department of Civil & Architectural Engineering），文中也把标注者描述为结构工程与材料力学方向的教育工作者。机械与航空航天则通过共享的固体力学成为真正意义上的共同领域：论文明确指出材料力学是土木、机械、航空航天与材料工程课程体系的核心科目，而扭转类题目（12.86%）的对象是轴，不是土木结构。题目中的构件都是教材式的一般构件，而非具名的建筑或桥梁，因此归入土木/结构的依据是学科主题与构件类型，而非某个可识别的实体工程。

## Evaluation

论文定义了三种 prompt 策略：PS+I（题干加示意图）、PS+I+DoI（题干、示意图加描述）与 PS+DoI（题干加描述，不给图）。VLM 三种都跑；LLM 因为只能读文本，只跑 PS+DoI——总共 14 组「模型–prompt」设定（3 策略 × 3 个 VLM，加上 PS+DoI × 5 个 LLM）。每道题在每种设定下生成五份独立回答，再经 DeepSeek-V3-0324 API 实现的多数投票归并为一个答案。判分是人工的：DoI 标注专家团队把全部 1,065 道题上的每一份模型回答都过了一遍，分两步看——推理是否沿着逻辑成立的步骤展开，以及最终答案是否正确——两条都满足才计 1 分，否则计 0；判分存疑的，经讨论达成共识后定夺。作者做过一次试点，用 Qwen-plus 在 200 道样题上充当自动 judge，与专家判断的一致率为 83%，但正式评测仍舍弃 LLM-as-judge 而采用人工评分，理由是数据集规模尚可掌控，且误差分析需要可靠的判断。唯一报告的指标是准确率。结果：Qwen-plus 56.6%（PS+DoI，总体最佳），DeepSeek-R1 52.4%，Doubao 48.5%，GPT-oss-120b 39.0%，Llama-70B 9.1%，GPT-3.5 1.0%（垫底）；成绩最好的三个模型都是在 PS+DoI 下取得各自最佳。对 Doubao 与 GPT-4o 这两个 VLM 而言，加上图片（PS+I 或 PS+I+DoI）相比纯文本的 PS+DoI 几乎没有提升。另有一项误差研究，让专家复核了 100 道所有模型都没做对的题，归纳出四类误差——Type K（知识类：掌握了正确的领域知识却没用上，例如内力判断失误）、Type C（计算类：公式对、算术错）、Type E（提取类：未能读懂或提取出 prompt 中的信息），以及 Type O（其他：回答不完整或答非所问）。给出 DoI 大幅削减了提取类误差：Qwen-VL 的 Type E 比例从 PS+I 下的 34% 降到 PS+DoI 的 6% 与 PS+I+DoI 的 5%，GPT-4o 则从 10% 降到 2.0% 与 3.0%。

## Main Contribution

作者把 SoM-1K 定位为首个专门评测基础模型解材料力学题目的大规模多模态 benchmark，并配套了 Descriptions of Images 这一 prompt 策略作为诊断工具。核心的实证主张有两条：现有模型在这类内容上败得很惨——最好也只有 56.6%；以及，与视觉-语言模型的设计预期相反，专家撰写的示意图文字描述比示意图本身更可靠，因为它消除了主导 VLM 误差的那种视觉误读失败模式。

## Key Design Ideas

- 示意图不是简单附上，而是被标注：DoI 是一份经专家订正、精心整理的示意图文字表述，刻意只写图中可见的信息，因而不会像思维链提示那样泄露解题步骤。
- 三种 prompt 策略构成一个关于模态的受控析因设计，「有没有图」与「有没有对图的正确解读」两种效应因此可以分开衡量。
- 沿变形形式与静定性两条正交轴分类，使结果能按难度切分报告，而不只有一个总分。
- 标准答案是教材的完整解答，判分要求推理步骤成立、最终答案正确，只对上答案并不得分。
- 全部 1,065 道题上的每份回答都由领域专家人工判分；试点已显示 LLM-as-judge 有 83% 的一致率，作者仍舍弃了它，为的是让误差分类建立在专家对推理过程的实读之上。
- 每个「题目–设定」采样五份回答再多数投票，以压低采样波动。

## Strengths

- DoI 消融分离出的是一个具体机制，而不只是几个总分：把原始图片输入换成经核验的描述后，提取类误差成倍下降，这就解释了「LLM 胜过 VLM」这一头条结论的成因，而非只作断言。
- 全部题目的判分完全由领域专家人工完成，两阶段标准加共识裁定，这个规模的 benchmark 能有这样的标签质量并不多见。
- 素材是真实的教材与竞赛内容，出处可查（公开数据集为每道题标注了书目、页码与图号），并刻意留出一个更难的超静定切片。
- 数据集已在 Hugging Face 公开，题干、DoI、标准答案与图片来源元数据都以结构化字段的形式给出。

## Limitations

- 范围刻意限定于线弹性材料力学；作者把结构动力学、塑性与非线性力学列为后续扩展方向，因此进阶或非线性的结构行为完全不在考察范围之内。
- 依赖图形的推理与计算误差在所有模型上都持续存在，论文也指出生成准确的工程图（内力图、变形形状）仍遥不可及——这是该 benchmark 识别出、却并未自己去评分的一项能力。
- Repository note: 评测是单轮文本生成，无工具、无计算器、无环境；Type C 计算误差因此都算在了模型头上，而这些模型放到任何现实的工程场景里，本来都会配有符号计算或数值计算工具；作者自己也观察到，K 类与 C 类误差有望借助检索或计算工具得到缓解。
- Repository note: 逐份回答的人工判分使该协议重跑起来代价高昂，论文也没有公开判分细则或自动化 harness，因此想为新模型复现分数，就得重做一遍专家评分（或退回到作者自己否掉的 LLM judge）。
- Repository note: 题目中的构件是教材式的一般构件——杆、轴、梁、刚架——而非具名的建筑、桥梁或土木结构，因此该 benchmark 衡量的是土木与机械工程共享的力学基础，而非土木特有的设计实务。
- Repository note: 素材多取自出版已久的教材，其中一部分是中文版实体书的扫描件；论文未报告针对模型训练数据的污染分析。TODO(reference)
