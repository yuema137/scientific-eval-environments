## Overview

HiSciBench 是一个层级式的多学科 benchmark，含 8,735 个实例，把科学能力排成五级递进的阶梯——事实素养、文献解析、文献问答、文献综述生成、数据驱动的科学发现——覆盖数学、物理、化学、生物、地理与天文六个学科，输入兼具多模态与跨语言。

## Summary

这套 benchmark 的立论是：「科学智能」不是单一能力，而是一道从阅读通向发现的阶梯；模型完全可能在低层显得称职，到了高层却撑不住。七个任务归入五个层级：L1 通用科学问答，L2 文献 OCR 与文献翻译，L3 单语与跨语文献问答，L4 主题引导的文献综述生成，L5 数据驱动的科学发现——最后一层要求模型写出并执行 Python 分析代码。每一层各有自己的评分协议：底层只看准确率，L4 用 LLM-as-judge 的评分细则加引文核验指标，L5 用基于执行的成功率。受评模型共 18 个，涵盖闭源与开源权重的文本模型、视觉语言模型以及面向科研的专用系统；论文报告的规律是：层级越高，性能下滑越陡。

## Tasks

8,735 个实例，分布在七个任务与六个学科上。据论文表 III：**L1.1 General Scientific QA**，1,200 道考察事实回忆的多项选择题，六个学科各 200 道（数学、物理、化学、天文、地理、生物）；**L2.1 Literature OCR**，629 个实例，要求从科学 PDF 中抽取文字、表格与公式（数学 208、物理 357、天文 19、生物 45）；**L2.2 Literature Translation**，629 个实例，学科分布同上，要求跨语言翻译科学文档；**L3.1 Monolingual Literature QA**，5,514 个实例，在单篇论文范围内回答问题（数学 821、物理 1,025、化学 886、天文 330、地理 500、生物 1,952）；**L3.2 Cross-lingual Literature QA**，629 个实例，提问语言与源文档语言不同（数学 208、物理 357、天文 19、生物 45）；**L4.1 Topic-guided Literature Review**，60 个综述生成主题，每学科 10 个；**L5.1 Data-driven Scientific Discovery**，74 个实例，模型拿到一个研究问题、一份数据集与领域背景，需要提出方法、用 Python 实现、执行分析并解释结果（化学 20、地理 27、生物 27）。L2 与 L3.2 的文档取自 arXiv。语言以英语为主，跨语言与翻译任务涉及中文。

## Domains

天文学是论文点名的六个学科之一，合计贡献 597 个实例：200 道通用科学问答、19 篇文献 OCR 文档、19 篇文献翻译文档、330 对单语文献问答、19 对跨语文献问答，以及 10 个文献综述主题。天文部分的任务都是面向文献的——解析 arXiv 上的天文论文、翻译、就论文答题并写成综述——而不是观测数据分析；L5.1 的发现类实例中没有天文，那一层只取自化学、地理与生物。共同领域即其余各学科：数学、物理、化学、生物，以及地球科学（论文中的「地理」学科）。

## Evaluation

每一层各有自己的协议。L1 与 L3 对照参考答案按分类准确率打分。L2.1 文献 OCR 对照参考抽取结果按词级准确率打分。L2.2 文献翻译用 BLEU。L4.1 分为内容质量与引文质量两块：内容由 LLM-as-judge 在五个维度上按 1–5 分打分——Coverage（综述覆盖该主题的全面程度）、Structure（组织的逻辑性与连贯性）、Relevance（内容与主题的相关程度）、Synthesis（跨文献整合观点的有效程度）与 Critical Analysis（方法论批评的深度以及对研究空白的识别）；引文则按可核验率、元数据准确率、忠实率与一项时效性指标打分。L5.1 采用基于执行的 Success Rate，考察生成程序的输出是否满足该任务设定的成功判据，例如在留出测试数据上达到目标性能；若代码无法执行或产出无效结果，成功率记为零。受评模型共 18 个，包括 GPT-5、DeepSeek-V3、DeepSeek-R1、Llama-3.1-Instruct-70B、Qwen3-32B、QwQ-32B、DeepSeek-R1-Distill-Qwen-32B，视觉语言模型 Qwen3-VL-8B、Qwen2.5-VL-7B、InternVL3-8B、InternVL3.5-8B 与 GLM-4.5V，以及 Tongyi-DeepResearch、SurveyX 等面向科研的专用系统。最醒目的结果是沿层级的陡峭下滑：GPT-5 在基础素养类任务上准确率最高可达 69%，到了发现层级只剩 25%。论文报告引文幻觉相当严重——通用模型的可核验率低于 20%，专用科研系统则为 71.4%。

## Main Contribution

把科学 benchmark 组织成层级而非平铺：HiSciBench 不用单一难度轴，而是把阅读层面的能力与综合层面、发现层面的能力分开，因此模型的科学能力究竟断在哪一层是可以定位的，不至于被平均抹掉。作者还为此配上了多模态文档输入与跨语言评估，以及在综述生成层揭露伪造参考文献的引文质量指标。

## Key Design Ideas

- 五个递进层级，从事实回忆一直到自主的数据驱动发现，使总分能够拆解成一张能力剖面图，而不是一个数。
- 各层采用与其相称的指标，而非一把统一的尺子：L1/L3 用准确率，L2.1 用词级准确率，L2.2 用 BLEU，L4 用基于细则的 LLM 判分加引文核验，L5 用基于执行的成功率。
- 综述层把引文质量与内容质量分开测量，让参考文献伪造单独成为一类失败模式。
- L5 把「发现」落到在给定数据集上可执行的代码上，因此得分取决于程序能否跑通并满足既定判据，而不是叙述是否听着合理。
- 文献类任务建立在 arXiv 上的真实论文之上，并保留文档图像，使多模态解析成为管线的一部分，而不是被绕过去。
- 跨语言赛道把英文源文档与中文提问、中文翻译配对，把科学理解与呈现语言分离开。
- 模型阵容有意混合通用文本模型、视觉语言模型与专门构建的科研系统——正因如此，三者之间引文可核验率的对比才是可测的。

## Strengths

- 层级不只是一句主张，而是落到了实处：每一层都有各自的实例、各自的输入形式与各自的评分协议。
- 逐学科的实例数表让整套题目的构成可以核查，包括某些层级并未覆盖全部六个学科这一点。
- L5 采用基于执行的评分，避免为无法核验的发现类主张给分。
- 引文可核验率是一个可直接测量的量，而通用系统与专用系统之间报告出的差距足够大，具有可操作性。
- 18 个模型横跨若干架构族系，为层级间的性能下滑提供了较宽的基础。

## Limitations

- benchmark 在学科与层级上的分布并不均衡：天文在七个任务中的三个各只有 19 个实例，L5.1 更是一个都没有，因此发现层级的结论只建立在化学、地理与生物之上。
- L3.1 主导了实例总数（8,735 中占 5,514），因此聚合分数在很大程度上就是一个单语文献问答分数。
- L2.2 文献翻译用 BLEU 打分，衡量的是表层重合度，而非科学上的正确性。
- 论文称该 benchmark「将会公开发布」，却未记录任何仓库或数据集 URL，因此其产物无法查验。
- Repository note: 任务以单轮生成为主；只有 L5.1 涉及代码执行，没有任何任务要求多步工具使用、规划或错误恢复，因此这套 benchmark 衡量的更多是模型的科学能力，而非 agent 行为。
- Repository note: 天文这一部分完全面向文献——解析、翻译天文论文，就其答题并写综述——不含任何观测数据分析，因此考察的是领域阅读理解，而非天文推断。
- Repository note: L4 的内容打分依赖 LLM judge，而其与人类专家评分者的一致性未见报告。
