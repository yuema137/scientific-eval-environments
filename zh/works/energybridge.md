# EnergyBridge (2026)

> [English](../../works/energybridge.md) | **简体中文**

## Overview

EnergyBridge 是一个面向住宅虚拟电厂（VPP）的 benchmark 与 agent 框架，把容量申报、住户授权与物理执行耦合在一起，并将分地区的 EnergyPlus 建筑能耗环境与一个基于 LLM 的用户参与模拟器（User Participation Simulator）配对。

## Summary

住宅 VPP 通过调度住户用电为电网提供灵活性，但物理灵活性只有在住户授权某项方案、且承诺的响应被真正兑现之后，才会转化为可依赖的容量。既有 benchmark 只评估控制，却略过了逐事件的授权环节。EnergyBridge 把容量申报、住户授权与物理执行串进单一工作流（VPP 请求 → 容量申报 → 住户专属方案 → 模拟同意 → 控制器或回退执行 → EnergyPlus 计量 → 审计）。它把针对天津与柏林的分地区 EnergyPlus 环境与一个基于 LLM 的用户参与模拟器结合起来，并公开人类数据与代码，以支持可复现、以人为本的电网灵活性研究。

## Tasks

主评估运行 50 次为期七天的模拟，覆盖五个固定家庭、两个地区（天津与柏林）与五种方法，产生 350 个「家庭-日」episode；每个「家庭-日」有一次 18:00–19:00 的需求响应事件，因而每种方法得到 70 个匹配情境。另有一项独立的容量申报审计使用留出事件：以 6 月的交付记录构成各方法的检索记忆，以 7 月的事件构成查询群组（每种方法 70 个留出事件；仓库中描述了在 7 月配置的七个事件日上共 840 次一日模拟）。人类验证收集了六种画像下 584 份完整且经同意的应答，产生 1,752 组「应答者–方法」配对判断（584 名应答者 × 各 3 种方法）。

## Domains

能源系统 / 住宅需求响应与电网灵活性（面向虚拟电厂的住户能源管理）。对 HVAC、电动车充电、电热水器、洗衣机、烘干机与洗碗机，连同不可控的基础负荷，进行建筑能耗建模。

## Evaluation

物理结果由 EnergyPlus（EnergyPlus 24.1.0）计量。所报告的指标包括：模拟的闸门接受（授权）率 `A = N_accepted / N_events`；事件窗口（VPP 窗口）能量；以及容量承诺可靠性 `F_m = P(accepted ∩ {0.8 ≤ C_actual / Ĉ ≤ 1.2})`，后者把接受率与容差内的交付准确性结合起来。住户授权由基于 LLM 的用户参与模拟器判定，它以六个行为维度（`p = (p_schedule, p_comfort, p_task, p_price, p_control, p_grid)`）编码，且提示词在验证前已冻结。对照 584 份按画像与事件匹配的人类角色扮演判断，模拟器保持了各方法的接受率排序（EnergyBridge，其次 HEMA，再次 MPC），平均绝对接受率误差为 5.3 个百分点（摘要）；具体到 EnergyBridge，LLM 与人类的接受率差距为 5.1 个百分点（LLM 77.1% vs. 人类 72.1%，表 2）。

## Typical Duration

环境以每小时六个分区时间步（10 分钟分辨率）模拟。主评估采用为期七天的模拟，每个「家庭-日」有一个 18:00–19:00 的事件窗口；MPC 使用一小时规划视野（六步），Rule+MILP 使用 30 分钟网格。每个 episode 的 wall-clock 时间与 token 预算未给出。

## Main Contribution

作者将 EnergyBridge 定位为一个面向「人类授权物理 agent」的端到端 benchmark，用于评估 agent 能否把物理灵活性潜力转化为经住户授权且可验证的电网资源，而不仅仅是生成可行的控制排程。它贡献了以真实人类数据为依据的评估（公开的 benchmark 环境、人类评估数据、物理模型与基线实现），以及一套把住户锚定、约束感知的方案生成、同意门控的执行与个性化容量申报结合起来的 agent 设计。

## Key Design Ideas

- 把三个阶段——容量申报、住户授权与物理执行——耦合进一个受评的工作流，补上了先前控制 benchmark 所略过的逐事件授权环节。
- 分地区的 EnergyPlus 建筑模型：天津与柏林分别按 GB 50176-2016 与 DIN 4108-4:2020-11 实例化各自的住宅围护结构，天津使用 CSWD 典型年 EPW 与归一化分时电价，柏林使用 2025 年逐时台站观测与 2025 年逐时电价序列。
- 覆盖六个行为维度、基于 LLM 的用户参与模拟器，经人类角色扮演验证，使接受率排序可替代成本高昂的人类试验。
- 容量承诺可靠性指标，只有当一个方案既被接受又在 ±20% 容差带内被交付时才给该方法记功。

## Strengths

- 以真实人类数据为依据：接受判断对照 584 份经同意的人类角色扮演应答（1,752 组配对判断）验证，模拟器保持了方法排序（论文）。
- 物理结果由 EnergyPlus 而非代理模型计量，横跨两个监管/气候地区（论文）。
- 公开人类数据、物理模型与基线实现以支持可复现性（论文、仓库）。

## Limitations

- 人类验证锚定在单一冻结的天津事件与六种画像上；摘要中 5.3 个百分点的平均绝对接受率误差量化了模拟器与人类之间尚存的分歧（论文）。
- Repository note: 授权由 LLM 模拟器而非真实住户判定，因此所报告的接受率与可靠性数字继承了模拟器的校准局限。
- Repository note: 论文的逐方法事件计数（如 70 个匹配情境 / 350 个 episode）与仓库的模拟计数（50 次七天与 840 次一日模拟）是在不同粒度上描述同一项研究；读者应同时参考两处以获得确切配置。
