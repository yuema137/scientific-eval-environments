# ATLAS: Discovering Agent Strategies through LLM-Guided Abstraction and Automata Learning (2026)

> **English** | [简体中文](../zh/works/atlas-agent-strategies.md)

> **First appeared:** 2026-08-14 · **Source:** [arXiv initial submission](https://arxiv.org/abs/2608.14352)

## Overview

ATLAS learns a finite-state behavioral model from many runs of an LLM agent, so that an analyst can read which strategies lead to success and where the agent loops or fails. Agent evaluation usually reports task success and leaves the raw traces for manual reading. ATLAS adds a step between the traces and the analyst: an LLM maps each action-observation pair to an abstract symbol, and a passive automata-learning algorithm merges the symbolic traces into a Markov chain whose states carry success labels and whose edges carry transition probabilities. The paper evaluates the result on a penetration-testing agent, both by inspecting the learned models and by feeding strategies extracted from them to smaller executor models.

## Summary

The abstraction runs in three LLM stages: interactions from all runs are categorized into action categories (with an optional target) and two-part "Value_Target" observation categories such as `DISCOVERY_SUID` or `ERROR_NONE`; similar labels are normalized into a compact vocabulary; and each interaction in each trace is assigned an (action-category, output-category) pair. Alergia, a state-merging algorithm (implemented in AALpy), learns a labelled Markov chain from these symbolic traces. Model transformations then shrink the chain for explanation: extracting the paths from the initial state to success as a loop-free graph, or keeping the top-k transitions per state, removing states from which success is unreachable, and collapsing strongly connected components. The authors state that the abstraction deliberately discards low-level detail.

## Evaluation

ATLAS is assessed in two ways.

- **Qualitative model inspection.** Traces are generated by DeepSeek V4 Flash, which also performs the abstraction. In one scenario the learned chain shows the agent starting with reconnaissance (`id`, `sudo -l`); after user discovery it either issues malformed commands (a recurrent failure mode) or proceeds to `sudo -l`, which leads to success within two steps with probability about 0.4. After reaching `EXPLOITABLE_SUDO` the agent succeeds immediately in 30% of cases and runs `sudo id` in 70%, which the paper calls inefficient.
- **Strategy transfer to small executors.** DeepSeek V4 Pro acts as a knowledge model that summarizes strategies from the learned chains; ministral-8b and ministral-14b execute under five modes, and each mode is scored by successful runs out of 60:

| Mode | ministral-8b | ministral-14b |
|---|---|---|
| Baseline (no model) | 5.0% | 1.7% |
| Common path | 1.7% | 11.7% |
| Minimal | 8.3% | 11.7% |
| Guided | 8.3% | 21.7% |
| Dynamic (traverse the chain alongside the environment, one suggested action at a time, with anti-repetition and dead-end detection) | 28.3% | 38.3% |

The paper also states that ministral-14b solved 50% of the benchmark tasks; its table shows 6 of 12 machines exploited, so this is a machine-level figure. Model transformations reduce, for example, a 41-state model to a small explanation model. Auditing is discussed as a use but not evaluated.

## Main Contribution

A pipeline that combines LLM-guided trace abstraction with automata learning to recover interpretable finite-state models of agent behavior, together with demonstrations that these models expose strategies and failure loops and can steer smaller models.

## Key Design Ideas

- Abstract each step as an (action category, observation category) pair, so the learned alphabet describes behavior rather than raw shell strings.
- Normalize LLM-proposed labels across all runs before assigning them, so traces share one vocabulary.
- Learn a stochastic model (Markov chain via Alergia) so that branch probabilities and success-labelled states are visible.
- Transform the learned model (success-path extraction, top-k pruning, unreachable-state slicing, SCC collapse) to produce short explanations.
- Use the learned model at run time as a guide for a weaker executor (dynamic mode).

## Strengths

- Turns a set of agent traces into a model whose branch probabilities quantify how often a strategy is followed and succeeds (paper).
- The transfer experiment checks that the extracted strategies carry usable information, not only that they are readable (paper).
- A replication package with learned models, traces, and source code is published (paper).

## Limitations

- The authors state that abstraction loses low-level detail and that category discovery requires a powerful LLM.
- Scalability to long trajectories, diverse or changing tasks, and heterogeneous environments is left open (paper).
- The evaluation is a proof of concept in penetration testing only; requirements for useful behavioral models are not yet defined (paper).
- SCC collapsing can absorb steps that matter for success; the paper gives a file read inside an SCC as an example.
- Repository note: transfer results rest on 60 runs per mode and executor; the most successful mode reaches 38.3%.
