# Enhancing Agentic Autonomous Scientific Discovery with Vision-Language Model Capabilities (2025)

## Overview

A 10-task benchmark for data-driven scientific discovery — mostly cosmological power-spectrum and molecular spectral-line problems — paired with a vision-language "plot judge" that grades an agent's generated figures against dynamically generated, domain-specific rubrics and feeds the verdict back as a self-correction signal.

## Summary

The work targets a specific blind spot in agentic scientific discovery: a coding agent that only sees text and stack traces cannot tell that a fitted curve misses a spectral feature or that a power spectrum has the wrong peak structure, because the failure is visible only in the plot. The authors add a vision-language model to the cmbagent multi-agent system as a verification checkpoint — a GPT-4o model first decomposes the natural-language task prompt into a rubric of checkable visual criteria, then a vision-capable judge inspects the produced figure against that rubric alone, without seeing the code, and returns a "continue" or "retry" verdict that drives the agent to revise. To measure whether this helps, the authors construct a 10-task benchmark of data-driven discovery problems whose datasets they generated themselves, and report pass@1 for code-only baselines, text-feedback variants, and VLM-feedback variants across three coding agents.

## Tasks

10 tasks, with datasets generated by the authors, grouped as: harmonic-oscillator dynamics (2 tasks — distinguishing damped from chirped oscillators); molecular spectral-line modelling (3 tasks — double-Gaussian profiles, self-absorption, hyperfine structure); epidemiological SEIR models (2 tasks — waning immunity and behavioural feedback); and cosmological power spectra (3 tasks — an incorrect spectral index, the EE spectrum, and an incorrect Hubble constant). Each task presents a dataset and a natural-language prompt; success is defined as the agent discovering the target feature — that is, identifying the correct underlying model — in the data. The tasks are specified in the paper's Appendix A. The authors state the multi-domain spread is deliberate, so that the evaluation is not biased toward a single field.

## Domains

Astronomy is the dominant domain: six of the ten tasks are astronomical — three cosmological power-spectrum problems (CMB spectral index, EE polarisation spectrum, Hubble constant) and three molecular spectral-line modelling problems from astrochemistry, where the object being modelled is an astronomical spectrum with self-absorption and hyperfine structure. Physics is a co-domain through the two harmonic-oscillator dynamics tasks. The two SEIR epidemiological tasks sit outside both and are present as a deliberate out-of-field control rather than as a claimed domain contribution.

## Evaluation

The reported metric is pass@1, defined as the probability that a single run of the system completes the workflow correctly, with success judged on whether the system identifies the correct underlying model in the data. Reported results: code-only baselines reach pass@1 of 0.2–0.3; cmbagent with text-only feedback reaches 0.4–0.5; cmbagent with VLM feedback reaches 0.7–0.8. The best configuration is cmbagent with a GPT-4.1 coding agent and a Gemini 2.5 Pro vision judge, at 0.8 pass@1. Coding agents compared: Gemini 2.5 Pro, GPT-4.1, and Claude Opus 4.1; judge and critic models: GPT-4o and Gemini 2.5 Pro, in both text-only and vision-capable variants. The in-loop plot judge itself is not scored numerically — it returns a binary "continue" or "retry"/"explore" verdict against the rubric. N/A — no runtime, wall-clock, token, or cost statistics are reported for any experiment. The authors note only that each trial is computationally expensive, which is their stated reason for reporting single-run pass@1 rather than repeated trials.

## Main Contribution

Introducing vision-language verification as a checkpoint inside an autonomous discovery loop — plots treated as verifiable artifacts graded against automatically generated, task-specific rubrics — together with a 10-task data-driven discovery benchmark on which VLM feedback raises pass@1 from 0.2–0.3 (code-only) to 0.7–0.8, and auditable reasoning traces from the judge that make the agent's self-correction decisions inspectable.

## Key Design Ideas

- The rubric is generated per task rather than fixed: a GPT-4o model decomposes the scientific requirements of the natural-language prompt into a set of checkable items.
- Rubrics use Pydantic schemas combining static fields (visual clarity, completeness, presentation) with dynamically generated scientific-accuracy criteria.
- The plot judge evaluates the figure solely against the rubric and without reference to the underlying code, so a plot that looks right for the wrong reason is not excused by readable source.
- The judge emits a binary control verdict ("continue" versus "retry"/"explore") rather than a score, making it directly usable as a loop-control signal.
- The same VLM signal is used both to correct errors and to steer exploratory analysis toward informative directions, not only to gate acceptance.
- Ablation is structured as code-only versus text-feedback versus vision-feedback, isolating what the visual channel adds over textual self-critique rather than over no feedback at all.
- Task domains deliberately extend past cosmology into spectral-line modelling, oscillator dynamics, and epidemiology, so that the gain cannot be attributed to cosmology-specific tuning of the underlying system.

## Strengths

- The ablation separates vision feedback from text feedback rather than from no feedback, so the reported gain is attributable to the visual channel specifically (0.4–0.5 with text-only versus 0.7–0.8 with VLM feedback).
- Rubrics are derived from each task's own prompt instead of a fixed checklist, so the criteria track what the specific scientific question requires.
- Withholding the code from the plot judge closes an obvious leak, since a plausible-looking script can otherwise excuse an incorrect figure.
- Tasks span four problem families, including two deliberately outside the authors' own cosmology specialty, which limits the risk that the result reflects tuning to a single field.
- The judge produces auditable reasoning traces, so the accept/retry decisions inside the loop are inspectable rather than opaque.
- The comparison covers three coding agents and two judge models rather than a single system pairing.

## Limitations

- The authors describe the pass@1 results as an initial proof of concept and state that statistically rigorous evaluation awaits a larger benchmark and more compute.
- Only single-run evaluation is reported, which the authors attribute to the combinatorial space of model combinations and the cost of each trial.
- Repository note: 10 tasks is a very small suite, and the pass@1 ranges are reported without per-task breakdowns or confidence intervals, so a difference of one task shifts a reported score by 0.1.
- Repository note: the paper makes no statement about releasing the benchmark tasks or datasets; only the cmbagent framework is stated to be open source, so the benchmark's reusability as an independent artifact is unestablished.
- Repository note: pass/fail appears to be assigned by the authors from whether the correct underlying model was recovered, with no separate human grader panel or automated checker described, so the scoring protocol is less formalised than the in-loop rubric machinery it measures.
- Repository note: the VLM judge is simultaneously part of the evaluated system and the mechanism under study, so the comparison measures the value of an added component rather than providing a judge that a third party could apply to other agents.
