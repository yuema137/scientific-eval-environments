# TS-Skill (2026)

> **English** | [简体中文](../zh/works/ts-skill.md)

## Overview

TS-Skill is a controlled benchmark for time-series question answering that decomposes analytical competence into three composable signal-level skills — temporal scale selection, temporal localization, and cross-interval integration — and reports a per-skill profile instead of a single aggregate TSQA score.

## Summary

Existing time-series QA benchmarks are organized by task type or by high-level reasoning category, which the authors argue makes it impossible to diagnose the signal-level capabilities actually driving performance. TS-Skill instead defines three composable analytical skills and builds questions whose required skill set is known by construction, so accuracy can be reported per skill and per skill combination. The benchmark is generated by **SKEvol**, a skill-guided agentic construction pipeline combining domain-aware seed-signal generation, skill-controlled question generation, metadata- and code-assisted answer construction, multi-phase signal-grounded verification, and human-in-the-loop curation. Evaluation across ten LLMs, VLMs, time-series-native models, and one tool-augmented agent shows substantial and uneven gaps across the three skills.

## Tasks

**3,000 QA items**, spanning the seven non-empty combinations of the three skills (SK1 alone through SK1+SK2+SK3). Questions are timestamp-aware and grounded in synthetic time series generated under domain context, covering 25 domain categories with 517 variables in total. The three skills are:

- **SK1 — temporal scale selection:** determining the temporal granularity at which the relevant pattern is most observable (fine-grained short events vs. coarse long-term trends).
- **SK2 — temporal localization:** identifying the timestamp, interval, or event where the relevant evidence resides, via explicit intervals, event anchoring, or cross-channel identification.
- **SK3 — cross-interval integration:** combining evidence across multiple separated temporal regions by counting, aggregation, comparison, or extremum operations.

Construction runs in two stages: domain-context-guided seed generation with metadata and skill annotations, then skill-targeted question generation with proposal agents, metadata/code-assisted answer construction, multi-phase verification (plot-based, rule-based, LLM-based), and human review.

## Domains

`Repository note:` no canonical science or engineering domain is assigned. The 25 domain categories (finance, healthcare, energy, traffic and transportation, environmental monitoring, web systems, and others) act as *context conditioning* for synthetically generated signals rather than as scientific tasks grounded in real field data; the evaluated capability is generic temporal reasoning over signals. Domain membership is therefore not claimed on the field axis.

## Evaluation

Questions are grouped by their required skill labels and models are scored within each group, so the output is a per-skill (and per-skill-combination) profile. Three answer protocols are reported:

- **Multiple choice** — accuracy and macro-F1 under a strict letter-match policy; unparseable outputs score 0.
- **Free-form** — an LLM judge ("Judge-Only") scoring open-ended answers.
- **Native form** — structured scoring that preserves heterogeneous answer formats.

Ten models across seven families were evaluated, including closed-source text LLMs and VLMs (GPT-o3-mini, GPT-4o, Claude Sonnet 4.5), open-source models (Qwen2.5-14B-Instruct, Qwen3-32B Thinking, DeepSeek-V3, Qwen2.5-VL-7B), a time-series-native model (ChatTS-14B), a fine-tuned task-specific model (Time-MQA), and one tool-augmented agent (GPT-5.4 with ReAct and time-series tools for trend detection, peak finding, windowing, and statistics).

Reported findings: SK3 is the dominant gap — non-agent models score near or below the random baseline of 0.259 (ChatTS-14B 0.290, Time-MQA 0.205), while the tool-augmented ReAct agent reaches 0.788 on standalone SK3 without closing the gap on compositional questions that also require localization and planning. Claude Sonnet 4.5 leads multiple-choice accuracy at 0.778.

## Main Contribution

A controlled, skill-labelled TSQA benchmark showing that skill-level evaluation surfaces temporal-reasoning failures that aggregate TSQA scores obscure — in particular that cross-interval integration is a near-universal failure mode for non-agentic models — together with SKEvol, the agentic pipeline that generates skill-controlled questions with verifiable answers at scale.

## Key Design Ideas

- Defining the decomposition at the *signal* level (scale, location, integration) rather than by task type or by high-level reasoning category.
- Making skill labels a construction-time property: questions are generated to require a specified skill set, so the profile is by design rather than by post-hoc annotation.
- Covering all seven skill combinations so that compositional skill demands can be separated from single-skill demands.
- Synthetic but domain-conditioned signals, which buys verifiable ground truth and scalable skill annotation.
- Multi-phase verification (plot-based, rule-based, LLM-based) plus human-in-the-loop curation before an item enters the benchmark.
- Timestamp-aware question phrasing, so localization is a real requirement rather than an artifact of context ordering.
- Three answer protocols (MCQ, free-form judged, native structured) so conclusions are not tied to a single scoring format.

## Strengths

- Skill labels are guaranteed by construction rather than inferred, which is what makes the per-skill profile trustworthy (paper).
- Includes a tool-augmented agent alongside prompted models, isolating where tools help (standalone SK3) and where they do not (compositional questions) (paper).
- Multiple scoring protocols reported, reducing the risk that a ranking is an artifact of MCQ formatting (paper).
- Verifiable answers with a documented multi-phase verification pipeline and human review (paper).

## Limitations

- The authors state TS-Skill uses controlled, domain-context-guided **synthetic** time series, which enables scalable skill annotation and verifiable answers but may not capture the noise, missingness, and distributional complexity of real deployments.
- Only three skills are defined; the authors name extension to real-world datasets, richer domain-specific tasks, multivariate settings, and additional skills as future work.
- `Repository note:` the benchmark is primarily an LLM/VLM question-answering evaluation — only one of the ten baselines is an agent with tools — so its agentic evidence rests on a single configuration.
- `Repository note:` the dataset link consulted is an anonymized Hugging Face repository, consistent with a work under review; a permanent artifact location is not stated in the sources consulted.
