> **English** | [简体中文](../zh/works/agent-evaluation-survey.md)

## Overview

*Survey on Evaluation of LLM-based Agents* is a comprehensive survey that organizes evaluation methods for LLM-based agents across five perspectives, and explicitly identifies gaps. It is included here as a reference paper, not a benchmark contribution.

## Summary

The survey provides the first comprehensive taxonomy of LLM-agent evaluation. It organizes existing work along five perspectives and explicitly identifies gaps that current benchmarks fail to cover — cost-efficiency, safety, robustness, and scalable evaluation methodology.

## Key Design Ideas

- Five-perspective taxonomy: foundational LLM capabilities, domain-specific benchmarks, generalist agent evaluation, agent benchmark core dimensions, evaluation frameworks and developer tools.
- Explicit gap identification alongside coverage — not only what exists but what is missing.

## Strengths

- Broad coverage of the LLM-agent evaluation literature at time of writing.
- Clear identification of underexamined dimensions.
- Serves as a "start here" reference for the field.

## Limitations
