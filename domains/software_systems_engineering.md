# Software & Systems Engineering

> **English** | [简体中文](../zh/domains/software_systems_engineering.md)

## Scope

Building and verifying software as engineering: code generation on real repositories, environment configuration, formal specification and verification. Web/UI agents and computer use are not software engineering.

## Related Works

- [SWE-bench](../works/swe-bench.md) — Patch generation for real GitHub issues in open-source Python repositories.
- [SWE-chat](../works/swe-chat.md) — In-the-wild coding-agent sessions with commit-grounded authorship attribution.
- [Enconda-bench](../works/enconda-bench.md) — Environment configuration for software-engineering agents.
- [AgentLens](../works/agentlens.md) — Java coding-assistant work over real open-source Spring Boot projects.
- [SysMoBench](../works/sysmobench.md) — Formal TLA+ specification of concurrent and distributed systems.
- [VCoT-Bench](../works/vcot-bench.md) — Formal verification of Rust programs in Verus.
- [Long-Horizon-Terminal-Bench](../works/long-horizon-terminal-bench.md) — Software engineering and scientific computing among its long-horizon terminal workflows.
