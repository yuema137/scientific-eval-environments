# October 2024 Monthly Report

> **English** | [简体中文](../zh/monthly/2024-10.md)

> **Coverage:** First appearances during 2024-10

## Month at a Glance

October 2024 is the first broad breakout month for agent evaluation across engineering, science, and embodied systems. MLE-bench, DevAI, ControlEval, FVEval, Embodied Agent Interface, and PARTNR make it clear that realistic evaluation now has to account for workflows, simulators, judges, and long-horizon state together.

## What Changed This Month

### [Scientific Agent Benchmarks](../topics/scientific_agents.md)

This group asks what counts as a defensible scientific benchmark once a field's artifacts, tools, and verification constraints stop looking like generic QA.

- [ControlAgent / ControlEval](../works/controleval.md): ControlEval is a benchmark of 500 control-system design tasks with varied design goals, released with ControlAgent — a multi-agent LLM system (central, task-specific, and Python-computation agents) that automates control design by iteratively tuning controller parameters and beats both LLM baselines and traditional toolbox-plus-human baselines.
- [DA-Code](../works/da-code.md): DA-Code is an agent-oriented data-science code-generation benchmark: complex data wrangling, analytics, and code generation tasks set in a controllable, executable sandbox environment, where even the best current LLMs reach only 30.5% accuracy.
- [DevAI / Agent-as-a-Judge](../works/devai.md): DevAI is a benchmark of 55 realistic automated-AI-development tasks with 365 hierarchical user requirements, released with Agent-as-a-Judge — an evaluation method in which agentic systems evaluate agentic systems, providing step-by-step feedback and matching human-evaluation reliability while far outperforming LLM-as-a-Judge.
- [FVEval](../works/fveval.md): FVEval is an NVIDIA benchmark for understanding language-model capabilities in formal verification of digital hardware, across three sub-tasks — generating SystemVerilog assertions from natural language, generating them from a testbench/design, and design-level verification reasoning — validated with the Cadence Jasper formal tool.
- [HARDMath](../works/hardmath.md): HARDMath is a benchmark dataset for challenging problems in applied mathematics — the analytical approximation techniques of a graduate asymptotics course — with auto-generated problems whose solutions are validated against numerical ground truths, plus 40 word problems in applied-science contexts; its HARDMath-mini test set holds 366 problems.

### [General Long-Horizon Agent Benchmarks](../topics/long_horizon_evaluation.md)

These papers push on the same bottleneck from different sides: once an agent must keep state across many steps, the benchmark has to expose where progress stalls.

- [DevAI / Agent-as-a-Judge](../works/devai.md): DevAI is a benchmark of 55 realistic automated-AI-development tasks with 365 hierarchical user requirements, released with Agent-as-a-Judge — an evaluation method in which agentic systems evaluate agentic systems, providing step-by-step feedback and matching human-evaluation reliability while far outperforming LLM-as-a-Judge.
- [Embodied Agent Interface](../works/embodied-agent-interface.md): Embodied Agent Interface (EAI) benchmarks LLMs for embodied decision making by decomposing the problem into four modules — goal interpretation, subgoal decomposition, action sequencing, and transition modeling — and scoring each against simulator states in VirtualHome and BEHAVIOR with a fine-grained error taxonomy.
- [MLE-bench](../works/mle-bench.md): MLE-bench evaluates machine-learning agents on machine-learning engineering: 75 ML-engineering competitions curated from Kaggle, where agents train models, prepare datasets, and run experiments to produce submissions graded against real Kaggle leaderboards — with OpenAI's o1-preview (AIDE scaffolding) reaching at least bronze-medal level on 16.9% of competitions.
- [PARTNR](../works/partnr.md): PARTNR benchmarks planning and reasoning in embodied multi-agent tasks — human-robot collaboration in household activities — at unmatched scale: 100,000 natural-language tasks spanning 60 houses and 5,819 unique objects in Habitat 3.0, with LLM planners analyzed across planning, perception, and skill execution.

### [Trajectory Evaluation](../topics/trajectory_evaluation.md)

Here the unit of judgment is no longer just the final answer. The trajectory itself becomes evidence about what the agent saw, decided, and missed.

- [AHA](../works/aha.md): AHA is an open-source vision-language model for detecting and reasoning over failures in robotic manipulation, framing failure detection as free-form natural-language reasoning; it is trained on the AHA dataset — a large-scale robotic failure-trajectory collection generated by procedurally perturbing successful simulation demonstrations with the FailGen framework — and surpasses GPT-4o in-context learning by 10.3%.
- [Embodied Agent Interface](../works/embodied-agent-interface.md): Embodied Agent Interface (EAI) benchmarks LLMs for embodied decision making by decomposing the problem into four modules — goal interpretation, subgoal decomposition, action sequencing, and transition modeling — and scoring each against simulator states in VirtualHome and BEHAVIOR with a fine-grained error taxonomy.

## Selected Topic Developments

[Scientific Agent Benchmarks](../topics/scientific_agents.md), [General Long-Horizon Agent Benchmarks](../topics/long_horizon_evaluation.md), [Trajectory Evaluation](../topics/trajectory_evaluation.md) stay at the center of this month, but the useful point is not the list itself. The useful connection is that scientific evaluation is being pushed into real multi-step environments rather than staying at the level of static domain QA.
