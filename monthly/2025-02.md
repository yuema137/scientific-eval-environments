# February 2025 Monthly Report

> **English** | [简体中文](../zh/monthly/2025-02.md)

> **Coverage:** First appearances during 2025-02

## Month at a Glance

February 2025 is where scientific-agent environments and long-horizon evaluation start to meet. MLGym, BixBench, EmbodiedBench, Robotouille, PDE-Controller, and TPBench push the repository beyond static problem sets into interactive research, embodied planning, and tool-grounded scientific tasks.

## What Changed This Month

### [Scientific Agent Benchmarks](../topics/scientific_agents.md)

This group asks what counts as a defensible scientific benchmark once a field's artifacts, tools, and verification constraints stop looking like generic QA.

- [AlchemyBench](../works/alchemybench.md): AlchemyBench is an end-to-end benchmark for LLM-driven materials synthesis, built on 17,000 expert-verified synthesis recipes from open-access literature: models predict raw materials and equipment, generate the synthesis procedure, and forecast characterization outcomes, graded by an expert-level LLM-as-a-Judge framework.
- [BixBench](../works/bixbench.md): BixBench is a benchmark for LLM-based agents in computational biology: over 50 real-world scenarios of practical biological data analysis with nearly 300 associated open-answer questions, in which agents explore datasets and perform long, multi-step analytical trajectories inside a containerized Jupyter environment.
- [MLGym](../works/mlgym.md): MLGym is the first Gym environment for AI-research tasks — enabling reinforcement-learning research on training agents — paired with MLGym-Bench, a benchmark of 13 diverse open-ended AI-research tasks across computer vision, NLP, reinforcement learning, and game theory.
- [PDE-Controller](../works/pde-controller.md): PDE-Controller brings LLMs to autoformalization and reasoning for PDE control: informal natural-language instructions are transformed into formal specifications (signal temporal logic), followed by reasoning and planning steps that improve the utility of PDE control for systems governed by heat and wave equations. Its datasets — human-written cases plus 2 million synthetic samples — and evaluation metrics constitute the benchmark component documented here.
- [TPBench](../works/tpbench.md): TPBench (Theoretical Physics Benchmark) is a dataset and study of AI reasoning in theoretical physics: 57 novel problems ranging from undergraduate to research level in high-energy theory and cosmology, built to be auto-verifiable and absent from public problem collections.

### [General Long-Horizon Agent Benchmarks](../topics/long_horizon_evaluation.md)

These papers push on the same bottleneck from different sides: once an agent must keep state across many steps, the benchmark has to expose where progress stalls.

- [EmbodiedBench](../works/embodiedbench.md): EmbodiedBench evaluates multimodal LLMs as vision-driven embodied agents at scale: 1,128 testing tasks across four environments, from high-level household semantics down to atomic navigation and manipulation actions, organized into six capability subsets — the best model, GPT-4o, scores only 28.9% on average.
- [MLGym](../works/mlgym.md): MLGym is the first Gym environment for AI-research tasks — enabling reinforcement-learning research on training agents — paired with MLGym-Bench, a benchmark of 13 diverse open-ended AI-research tasks across computer vision, NLP, reinforcement learning, and game theory.
- [Robotouille](../works/robotouille.md): Robotouille is an asynchronous planning benchmark for LLM agents: long-horizon cooking tasks where progress requires managing overlapping actions and interruptions — ReAct with GPT-4o achieves 47% on synchronous tasks but only 11% on asynchronous ones.

### [Skill Hierarchy](../topics/skill_hierarchy.md)

These works stop treating capability as a single score and instead separate the stack of subskills that a result depends on.

- [EmbodiedBench](../works/embodiedbench.md): EmbodiedBench evaluates multimodal LLMs as vision-driven embodied agents at scale: 1,128 testing tasks across four environments, from high-level household semantics down to atomic navigation and manipulation actions, organized into six capability subsets — the best model, GPT-4o, scores only 28.9% on average.
- [GATE](../works/gate.md): GATE (Graph-based Adaptive Tool Evolution Across Diverse Tasks) is a framework that dynamically constructs and evolves a hierarchical graph of reusable tools for LLMs. It is included in this repository for completeness of coverage of the initial reference list, but note: **its actual subject is tool-making for LLMs, not skill-hierarchy evaluation of agents** — the maintainer input's Skill-Hierarchy classification was based on a superficial name match rather than the paper's content.

## Selected Topic Developments

[Scientific Agent Benchmarks](../topics/scientific_agents.md), [General Long-Horizon Agent Benchmarks](../topics/long_horizon_evaluation.md), [Skill Hierarchy](../topics/skill_hierarchy.md) stay at the center of this month, but the useful point is not the list itself. The useful connection is that scientific evaluation is being pushed into real multi-step environments rather than staying at the level of static domain QA.
