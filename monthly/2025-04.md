## What Changed This Month

### [Scientific Agent Benchmarks](../topics/scientific_agents.md)

This group asks what counts as a defensible scientific benchmark once a field's artifacts, tools, and verification constraints stop looking like generic QA.

- [FEABench](../works/feabench.md): FEABench evaluates whether LLMs and LLM agents can simulate physics, mathematics, and engineering problems end to end using finite element analysis (FEA): reasoning over a natural-language problem description and operating COMSOL Multiphysics® through its API to compute the answer.
- [HLS-Eval](../works/hls-eval.md): HLS-Eval is a benchmark and framework for evaluating LLMs on high-level synthesis design tasks: 94 unique designs with natural-language descriptions and testbenches, over two tasks — generating HLS code from natural language and performing HLS-specific edits to optimize performance and hardware efficiency — scored by parseability, compilability, runnability, and synthesizability on Vitis HLS.
- [Integrating Large Language Models for Automated Structural Analysis](../works/integrating-large-language-models-for-automated-st.md): A hand-curated benchmark of twenty structural analysis word problems (SAWPs) on 2D frames with ground-truth solutions, used to compare four LLMs inside an OpenSeesPy-backed framework and to measure the run-to-run stability of the best of them.
- [LLM-SRBench](../works/llm-srbench.md): LLM-SRBench is a benchmark of 239 challenging problems for scientific equation discovery with LLMs, designed to prevent trivial memorization: LSR-Transform recasts common physical models into less common mathematical representations, and LSR-Synth introduces synthetic, discovery-driven problems requiring data-driven reasoning.
- [MLRC-Bench](../works/mlrc-bench.md): MLRC-Bench asks whether language agents can solve machine-learning research challenges: a curated suite of 7 competition tasks where agents must propose and implement novel research methods, scored objectively by how much of the gap between a provided baseline and top human participants they close — where the best agent closes only 9.3%.

### [Evaluator Reliability & Validation](../topics/evaluator_reliability_validation.md)

A useful way to read this cluster is to ask which hidden part of evaluation it makes visible.

- [AgentRewardBench](../works/agentrewardbench.md): AgentRewardBench is a benchmark that measures how well automatic evaluators — LLM judges and the rule-based scorers shipped with web agent benchmarks — reproduce expert judgements of agent trajectories. It contains 1,302 trajectories drawn from 5 web benchmarks and 4 agent LLMs, each reviewed by an expert annotator for success, side effects, and repetition.

### [Trajectory Evaluation](../topics/trajectory_evaluation.md)

Here the unit of judgment is no longer just the final answer. The trajectory itself becomes evidence about what the agent saw, decided, and missed.

- [AgentRewardBench](../works/agentrewardbench.md): AgentRewardBench is a benchmark that measures how well automatic evaluators — LLM judges and the rule-based scorers shipped with web agent benchmarks — reproduce expert judgements of agent trajectories. It contains 1,302 trajectories drawn from 5 web benchmarks and 4 agent LLMs, each reviewed by an expert annotator for success, side effects, and repetition.
