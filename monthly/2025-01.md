# January 2025 Monthly Report

> **English** | [简体中文](../zh/monthly/2025-01.md)

> **Coverage:** First appearances during 2025-01

## Month at a Glance

January 2025 is a breadth month that mixes frontier general exams with domain-heavy scientific tasks. Humanity's Last Exam, Gravity-Bench, thermodynamics problem solving, and materials hypothesis generation show the archive stretching from broad capability ceilings to discipline-specific scientific reasoning.

## What Changed This Month

### [Scientific Agent Benchmarks](../topics/scientific_agents.md)

This group asks what counts as a defensible scientific benchmark once a field's artifacts, tools, and verification constraints stop looking like generic QA.

- [Gravity-Bench-v1](../works/gravity-bench.md): Gravity-Bench-v1 is an agentic benchmark on gravitational-physics discovery: the agent observes a simulated two-body gravitational system, plans data collection within an experimental budget, and analyzes the data to uncover concealed physics — including out-of-distribution modified physics that cannot be answered from memorized textbook knowledge.
- [Humanity's Last Exam](../works/hle.md): Humanity's Last Exam (HLE) is a multi-modal benchmark at the frontier of human knowledge, designed as the final closed-ended academic benchmark of its kind: 2,500 questions across dozens of subjects — mathematics, humanities, and the natural sciences — developed globally by subject-matter experts. It is a general academic benchmark rather than an agent benchmark (see the repository note under Limitations).
- [Using Large Language Models for Solving Thermodynamic Problems](../works/llm-thermodynamics.md): A benchmark study that evaluates five large language models on 22 chemical-engineering thermodynamics problems, with answers graded by trained human experts in the manner of academic exam grading.
- [Materials Hypothesis Generation](../works/materials-hypothesis.md): This work evaluates goal-driven, constraint-guided LLM agents for materials discovery: given research goals and specific constraints, the agents generate hypotheses for achieving them, scored by a scalable evaluation metric designed to emulate how a materials scientist would critically judge a hypothesis.
- [MedAgentBench](../works/medagentbench.md): MedAgentBench is a realistic virtual EHR environment to benchmark medical LLM agents: 300 patient-specific, clinically derived tasks from 10 categories written by human physicians, over realistic profiles of 100 patients with more than 700,000 data elements, in a FHIR-compliant interactive environment.

### [General Long-Horizon Agent Benchmarks](../topics/long_horizon_evaluation.md)

These papers push on the same bottleneck from different sides: once an agent must keep state across many steps, the benchmark has to expose where progress stalls.

- [EmbodiedEval](../works/embodiedeval.md): EmbodiedEval evaluates multimodal LLMs as embodied agents in an interactive 3D simulation framework: 328 distinct tasks within 125 varied 3D scenes, spanning navigation, object interaction, social interaction, attribute question answering, and spatial question answering.

### [Resource-aware Evaluation](../topics/resource_aware_evaluation.md)

These papers make efficiency part of the evaluation target, so success only counts when the agent reaches it without spending blindly.

- [Gravity-Bench-v1](../works/gravity-bench.md): Gravity-Bench-v1 is an agentic benchmark on gravitational-physics discovery: the agent observes a simulated two-body gravitational system, plans data collection within an experimental budget, and analyzes the data to uncover concealed physics — including out-of-distribution modified physics that cannot be answered from memorized textbook knowledge.

## Selected Topic Developments

[Scientific Agent Benchmarks](../topics/scientific_agents.md), [General Long-Horizon Agent Benchmarks](../topics/long_horizon_evaluation.md), [Resource-aware Evaluation](../topics/resource_aware_evaluation.md) stay at the center of this month, but the useful point is not the list itself. The useful connection is that scientific evaluation is being pushed into real multi-step environments rather than staying at the level of static domain QA.
