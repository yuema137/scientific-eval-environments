## Month at a Glance

- Four works entered the knowledge base this month, all new releases first public in September 2024: [SUPER](../works/super.md), [DSBench](../works/dsbench.md), [CORE-Bench](../works/core-bench.md), and [ChemEval](../works/chemeval.md).
- All four sit under [Scientific Agent Benchmarks](../topics/scientific_agents.md), and they share one move: hand the agent the raw materials of real scientific work instead of a pre-packaged question, then measure how little of it gets finished.
- The tightest cluster is research reproduction. [CORE-Bench](../works/core-bench.md) and [SUPER](../works/super.md) both start from released research artifacts but cut the task at different joints, and both report ceilings at or below roughly one in five.
- [DSBench](../works/dsbench.md) and [ChemEval](../works/chemeval.md) extend the frontier into data science and chemistry. ChemEval is the month's one static capability profile rather than an agentic solve rate, and the only work also placed on [Skill Hierarchy](../topics/skill_hierarchy.md).

## What Changed This Month

**Scientific-agent evaluation moved from pre-formatted problems to the raw artifacts of real work — and every new ceiling is low.** The familiar evaluation path hands a model a question that has already been cleaned up for it: a curated task statement, a self-contained problem, an input formatted so the model can start reasoning immediately. That measures reasoning once the setup is done, but it says nothing about the setup itself — the dependency that will not install, the multi-table data file, the paper whose numbers have to actually come back. All four works this month change what the agent is given. Each one supplies the unpolished input a practitioner would face and scores whether the practitioner's result is produced, and each reports that only a small fraction of the work gets done.

The clearest cluster is research reproduction, where [CORE-Bench](../works/core-bench.md) and [SUPER](../works/super.md) start from the same place — a study's own released code and data — but cut the task at different joints. [SUPER](../works/super.md) (from AI2) isolates the upstream step of getting someone else's repository to run at all: resolving dependencies, fixing errors, and executing code from real ML/NLP repositories in the GitHub wild, graded over 45 end-to-end problems with expert solutions, 152 sub-problems that isolate individual setup challenges, and 602 auto-generated problems. The best model, GPT-4o, solves 16.3% of the end-to-end set (46.1% of scenarios). [CORE-Bench](../works/core-bench.md) measures the reproduction outcome instead — whether a published study's reported results can be regenerated from its provided code and data — across 270 tasks drawn from 90 papers in computer science, social science, and medicine, at three difficulty levels and in both language-only and vision-language forms, with a parallelized evaluation harness that cuts days off a sequential run. Its strongest baseline reaches 21% accuracy on the hardest level. Read together, SUPER measures whether the code runs; CORE-Bench measures whether the numbers return — and both stop well short of solving even that floor of research automation.

[DSBench](../works/dsbench.md) pushes the same realism into data science. Rather than clean toy tables, its 540 tasks (466 data-analysis and 74 data-modeling) carry long textual contexts, images, and multi-table data drawn from competition sources and Kaggle, and the agent must turn an instruction plus data files into a working solution. Separating analysis from modeling isolates two distinct competences, and both come back short: the best agent solves 34.12% of analysis tasks and shows a 34.74% relative performance gap on modeling — a citable marker of how far agents remain from expert-level data-science work.

[ChemEval](../works/chemeval.md) is the month's exception in form: not an agentic solve rate but a static capability profile. It organizes chemical capability into four progressive levels and 12 dimensions over 42 tasks, mixing open-source data with tasks authored by chemical experts, and evaluates 12 models under zero- and few-shot prompting. Instead of one ceiling it surfaces a trade-off: general models such as GPT-4 and Claude-3.5 lead on literature understanding and instruction following but fall behind on advanced chemical knowledge, while specialized chemistry models show the reverse. Because the levels are progressive — later capabilities presuppose earlier ones — the profile reads as a capability structure, which is why the work also belongs to [Skill Hierarchy](../topics/skill_hierarchy.md). The result stops at static, single-turn QA rather than an interactive setting, and the reported counts are version-specific: the arXiv version states 42 tasks over 12 dimensions, while the later ICLR version reported by the official repository expands to 62 textual and multimodal tasks over 13 dimensions.

## Selected Topic Developments

### [Scientific Agent Benchmarks](../topics/scientific_agents.md)

All four works land on this topic, and they separate into recognizable design lines rather than a single pile. The reproduction line ([CORE-Bench](../works/core-bench.md), [SUPER](../works/super.md)) defines a boundary within the topic: both begin from released research artifacts, but one grades environment setup and execution while the other grades whether reported results are recovered — two consecutive links of the same chain, benchmarked separately. The data-science line ([DSBench](../works/dsbench.md)) keeps the agentic, produce-a-solution framing but swaps reproduction for open-ended analysis and modeling over messy, multimodal inputs. The domain-knowledge line ([ChemEval](../works/chemeval.md)) steps off the agentic axis entirely, using static level-and-dimension profiling to expose a general-versus-specialist split that a single solve rate would hide.

The same works register on two adjacent axes:

- On [General Long-Horizon Agent Benchmarks](../topics/long_horizon_evaluation.md), [SUPER](../works/super.md) counts because its repo-setup-and-execution episodes are interactive and long-horizon — a task defined by the length of the setup trajectory, not a single query.
- On [Skill Hierarchy](../topics/skill_hierarchy.md), [ChemEval](../works/chemeval.md)'s progressive levels act as an explicit capability ordering, where advanced chemical competence presupposes the lower levels rather than being one more flat category.
