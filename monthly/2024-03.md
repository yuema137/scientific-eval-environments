# March 2024 Monthly Report

> **Coverage:** First appearances during 2024-03

## Month at a Glance

- One work entered the knowledge base this month, and it is a new release: [BrainBench](../works/brainbench.md), first public on 2024-03-04.
- Its argument is a shift in what a knowledge test measures: instead of asking whether a model can recall an established finding, ask whether it can predict how an unseen experiment turns out.
- The mechanism is a result-altered abstract pair. A real Journal of Neuroscience abstract is set against a coherently rewritten version whose outcome is changed, and the model picks the true one by perplexity — no answer extraction and no judge.
- The reported evidence is that generalist LLMs beat human neuroscience experts at this forecast, and that their confidence tracks their accuracy. The boundary is equally clear: this is a static two-alternative task, not an agent evaluation, and the headline numbers still await full-paper validation.

## What Changed This Month

**A scientific-knowledge test moves from recall to forecast.** Most benchmarks of a model's scientific knowledge measure what it can reproduce: retrieve a fact, restate a mechanism, match a recorded result. That is backward-looking — it scores whether the model has absorbed what the literature already reports. [BrainBench](../works/brainbench.md) changes the measured quantity. It asks whether the model can anticipate the result of an experiment it has not seen written down. Each item pairs an original abstract from the Journal of Neuroscience with a version altered to change the outcome while staying internally coherent, so style and plausibility are held roughly constant and only the reported result differs; the model chooses by comparing perplexity across the two versions, which needs no answer parsing and no separate LLM grader. Confidence calibration is treated as a first-class property rather than an afterthought, because a forecaster is only useful when its stated confidence predicts when it is right.

The evidence is a 200-case dataset spanning five journal sections — behavioral/cognitive, systems/circuits, neurobiology of disease, cellular/molecular, and development/plasticity/repair — on which LLMs surpass the human expert cohort at predicting outcomes, higher model confidence tracks higher accuracy, and a neuroscience-tuned model (BrainGPT) does better still.

The result stops well short of a general claim. BrainBench is a single-pass forced choice, not an interactive agent setting, so its finding speaks to a model's internalized sense of how experiments come out, not to how an agent would plan or run one. It is recorded here for that evaluation methodology — outcome prediction scored with calibration — which is directly relevant to judging scientific agents even though the benchmark itself is not one. The tuned BrainGPT model is a modeling contribution that sits outside this repository's scope, and the specific accuracy figures are marked for validation against the full paper rather than repeated as settled.

## Selected Topic Developments

### [Scientific Agent Benchmarks](../topics/scientific_agents.md)

BrainBench sits at the edge of this topic rather than in its main cluster. The other works here anchor correctness to executable checks, measured values, or reproduced results from scientific practice; BrainBench instead contributes a methodology — predicting an experimental outcome and scoring the prediction's calibration — that the topic tracks for how it judges scientific competence, not because it puts an agent to work. Two design choices are what make it worth recording alongside the agent benchmarks: the result-altered abstract pair isolates outcome knowledge from surface fluency, and perplexity-based scoring removes the judge from the loop entirely. Read it as a reference point for "models as scientific forecasters," with the standing caution that beating experts on a static two-alternative choice is not evidence of agentic scientific ability.
